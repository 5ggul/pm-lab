공식 원자료와 민간 인테리어 견적 통계를 같은 숫자로 취급하지 않습니다. 화면의 숫자는 출처와 계산방식에 따라 네 유형으로 구분합니다.

민간 견적 통계 공개 기준

현재 v6 검수 데이터에는 공개 가능한 실제 익명 견적 통계가 없습니다. 표본이 없거나 조건이 섞인 상태에서 ‘전국 평균 32평’ 같은 숫자를 만들지 않습니다.

공개 기준은 전체 누적 80건이 아니라 같은 지역·평수구간·공사범위·욕실 수·샷시·VAT·폐기물 조건에서 검수 승인 후 유효 표본이 80건 이상인 세그먼트에 적용합니다.

익명 견적 검수 파이프라인

단계처리공개 여부
수집구조화 필드만 pending으로 비공개 저장비공개
중복조건·총액·12공종을 정규화한 SHA-256 fingerprint가 동일한 후속 제출 분리비공개
품질C등급, 핵심조건 미확인, 별도금액 미기재 표본은 통계 후보에서 제외하거나 추가 검수비공개
승인reviewer status가 approved인 표본만 집계 후보비공개
이상치같은 세그먼트 승인 후보가 20건 이상일 때 log(총액)의 MAD modified z-score |z| > 3.5를 분리개별값 비공개
집계이상치 분리 후 유효 표본이 80건 이상이면 P25·중앙값·P75·표본수 생성집계만 공개

이상치로 분류된 원본값을 수정하거나 상한·하한에 맞춰 바꾸지 않습니다. 집계에서는 제외 수를 별도 기록하고, 개별 제출 ID나 검수 메타데이터는 공개 JSON에 넣지 않습니다.

공공자료 사용 범위

한국건설기술연구원의 건설공사비지수·표준시장단가·표준품셈과 조달청 가격정보는 공사비 환경과 공공 원가 참고층으로 사용합니다. 이 자료는 민간 아파트 턴키 계약의 실제 평균 견적과 같은 데이터가 아닙니다.

KOSIS API 키처럼 인증이 필요한 정보는 브라우저 코드에 넣지 않습니다. 수집이 필요할 때는 서버 또는 CI에서 가져온 뒤 검증된 정적 JSON만 프런트에서 읽는 구조를 사용합니다.

계산식 공개

화면계산
견적 검사조건 보정 합계 = 견적서 표시 총액 + 금액이 확인된 별도 항목
A/B/C 비교각 업체에서 `포함`으로 입력한 공종 금액만 합산. 미기재는 0원으로 처리하지 않음
VAT 계산사용자가 ‘10% 추가’를 선택한 경우 입력 소계 × 10%
샷시 면적개수 × 가로(mm) × 세로(mm) ÷ 1,000,000
민간 견적 분포정렬된 유효 표본의 선형보간 P25·중앙값·P75. 세그먼트 유효 표본 80건 미만이면 값 자체를 공개하지 않음
