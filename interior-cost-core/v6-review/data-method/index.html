민간 견적 통계 공개 기준

현재 v6 검수 데이터에는 공개 가능한 실제 익명 견적 통계가 없습니다. 표본이 없거나 조건이 섞인 상태에서 ‘전국 평균 32평’ 같은 숫자를 만들지 않습니다.

현재 내부 규칙은 공개 통계 최소 표본을 80건으로 두고 있습니다. 표본이 쌓여도 평수·지역·공사범위·샷시·욕실 수처럼 결과를 크게 바꾸는 조건이 충분히 구분되지 않으면 하나의 분포로 합치지 않습니다.

공공자료 사용 범위

한국건설기술연구원의 건설공사비지수·표준시장단가·표준품셈과 조달청 가격정보는 공사비 환경과 공공 원가 참고층으로 사용합니다. 이 자료는 민간 아파트 턴키 계약의 실제 평균 견적과 같은 데이터가 아닙니다.

KOSIS API 키처럼 인증이 필요한 정보는 브라우저 코드에 넣지 않습니다. 수집이 필요할 때는 서버 또는 CI에서 가져온 뒤 검증된 정적 JSON만 프런트에서 읽는 구조를 사용합니다.
