민간 견적 통계 공개 기준

현재 v6 검수 데이터에는 공개 가능한 실제 익명 견적 통계가 없습니다. 표본이 없거나 조건이 섞인 상태에서 ‘전국 평균 32평’ 같은 숫자를 만들지 않습니다.

공개 기준은 전체 누적 80건이 아니라 같은 지역·평수구간·공사범위·욕실 수·샷시·VAT·폐기물 조건에서 검수 승인 후 유효 표본이 80건 이상인 세그먼트에 적용합니다.

공공자료 사용 범위

한국건설기술연구원의 건설공사비지수·표준시장단가·표준품셈과 조달청 가격정보는 공사비 환경과 공공 원가 참고층으로 사용합니다. 이 자료는 민간 아파트 턴키 계약의 실제 평균 견적과 같은 데이터가 아닙니다.

공공 단가 조회의 1순위 원천은 공공데이터 ID 15129415 나라장터 가격정보현황서비스의 getStdMarkUprcinfoList입니다. 공표일자 범위에서 같은 공사구분·단가구분·공종·품명·규격·단위의 최근 행을 사용하고, 재료비단가·노무비단가·경비단가 합계를 별도 산술 계산합니다. 공공데이터 ID 15151298의 2025-08-04 6,263행 스냅샷은 스키마·수치 수동 대조용이며 라이브 원천 실패 시 최신 데이터로 자동 대체하지 않습니다.

라이브 공공단가는 550일 조회창에서 중복 제거 후 5,000행 이상이어야 하고, 최근 공표일이 730일을 넘게 오래되면 게시를 중단합니다. API가 정상 응답해도 이 완전성·신선도 조건을 통과하지 못하면 production 데이터로 채택하지 않습니다.

공공데이터포털·KOSIS API 키처럼 인증이 필요한 정보는 브라우저 코드에 넣지 않습니다. 수집이 필요할 때는 서버 또는 CI에서 가져온 뒤 검증된 정적 JSON만 프런트에서 읽는 구조를 사용합니다.

배포 승인과 release 후보

검수 workflow의 기술 테스트가 모두 통과해도 자동으로 production 배포를 허용하지 않습니다. 실제 배포는 운영자가 프리뷰를 확인하고 명시적으로 승인한 뒤에만 가능하다는 수동 게이트를 별도로 둡니다.

상태의미배포 판단
blocked_technical필수 production 검증·출력·무결성 조건 중 하나 이상 실패배포 금지
blocked_manual_approval기술 검증은 통과했지만 운영자 명시 승인 없음배포 금지
core_only운영자 승인과 핵심 페이지 준비 완료. 미준비 공공단가·견적통계는 noindex 유지핵심 페이지만 출시 후보
full_data운영자 승인 + 공공단가 + 견적통계까지 공개 기준 충족전체 데이터 기능 출시 후보
production 후보는 파일별 SHA-256을 기록한 release-manifest.json과 manifest 자체의 release-manifest.sha256을 생성합니다. quote-admin, raw/pending/private/secret 경로, .env, SQL·TOML·MJS 파일, API 비밀키 패턴, 검수용 NOINDEX REVIEW 문구가 후보에 섞이면 CI에서 실패합니다.

검수 workflow는 배포를 실행하지 않고 review build, production candidate, release review artifact만 생성합니다. 실제 production 전환은 별도 승인된 release 경로에서만 수행하는 것을 원칙으로 합니다.

출시 직전 preflight

출시 직전 검증은 실제 외부 조건을 확인하되 저장소와 production을 변경하지 않는 별도 단계로 분리합니다. 권장 순서는 review CI → 실API preflight → 실제 도메인 preflight → 운영자 프리뷰 승인 → 승인된 release 경로입니다.

preflight확인산출물변경 여부
공공단가 실API조달청 15129415 실제 응답, 5,000행 하한, 최신 공표일, 공종코드 커버리지, 표준시장단가·시장시공가격 행수public-price-preflight.json + 임시 snapshot artifactrepository write·commit·push·deploy 없음
production 도메인HTTPS, canonical base URL, localhost·예약 테스트 호스트 차단, GitHub Pages 프리뷰 기본 차단, production build·무결성실제 도메인 production candidate + readiness + manifest artifactdeploy 없음
GitHub Pages 주소는 프리뷰 리허설에서만 명시적으로 허용할 수 있습니다. 이 예외는 production 승인으로 해석하지 않습니다. 실제 도메인 preflight도 운영자 승인 입력을 별도로 기록할 뿐 배포 동작은 실행하지 않습니다.
