견적검수실

받은 인테리어 견적을 같은 공종·수량·사양·포함조건으로 옮겨 비교하기 위한 정보형 도구입니다.

업체 중개안 함견적 저장브라우저

무엇을 합니다

  • 견적서를 12개 표준 공종으로 옮겨 누락·별도·1식 항목을 확인합니다.
  • 업체 A/B/C의 금액보다 VAT·폐기물·샷시 같은 포함조건을 먼저 맞춥니다.
  • 욕실·주방·샷시·철거처럼 공종마다 다른 수량·사양을 별도 도구로 확인합니다.
  • 공공 공사비 자료와 사용자 입력 계산값, 민간 견적 표본을 서로 다른 데이터 유형으로 표시합니다.

무엇을 하지 않습니다

  • 인테리어 업체를 추천하거나 연결하지 않습니다.
  • 출처 없는 ‘전국 평균’, ‘적정가’, ‘평당 시세’를 만들지 않습니다.
  • 실측·계약서·현장 확인을 대신하지 않습니다.
  • 법률·세무·하자 책임에 대한 전문 자문을 제공하지 않습니다.

편집 원칙

금액보다 조건을 먼저 적고, 예시 데이터와 실제 표본을 구분합니다. 공식 자료는 원가 환경 참고층으로만 사용하며 민간 아파트 턴키 평균으로 환산하지 않습니다. 계산식과 변경이력은 공개합니다.
