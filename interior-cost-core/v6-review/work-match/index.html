견적 문구 공종 매칭

업체가 적은 문구를 12개 표준 공종 후보와 확인 질문으로 분해합니다. 규칙이 후보를 제안할 뿐 자동 확정하지 않으며, 1식 금액을 세부 항목에 임의 배분하지 않습니다.

표준 공종12저장 방식현재 탭 메모리공공단가확인 중

입력 원칙

  1. 업체명·주소·전화번호 같은 개인정보는 넣지 않습니다.
  2. 한 줄에 한 견적 항목을 넣으면 후보를 분리하기 쉽습니다.
  3. ‘1식’은 세부 범위를 확인할 후보로만 펼칩니다.
  4. 후보가 여러 개면 사용자가 직접 선택합니다.
입력 줄0
공종 후보0
사용자 확정0
견적 문구를 입력하세요공종명·1식·포함·별도 표현을 규칙으로 읽어 표준 공종 후보를 제안합니다.

확정한 공종

체크한 후보만 이 목록에 남습니다. 자동 선택은 없습니다.

아직 사용자가 확정한 공종이 없습니다.

매칭 기준

01표현 매핑화장실→욕실, 샷시→창호처럼 기존 12공종 별칭 규칙을 사용합니다.
021식 분해욕실·주방·창호 1식은 확인해야 할 세부 후보로 펼치되 금액을 나누지 않습니다.
03애매함 유지‘타일’처럼 공간이 불명확한 표현은 욕실/바닥 후보를 함께 보여줍니다.
04공공단가 연결공식 데이터가 수집되면 후보 검색어와 일치하는 조달청 참고행만 보여줍니다.
