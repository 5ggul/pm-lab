연락

오류·정정 요청

공종 분류, 계산식, 출처 설명, 깨진 링크처럼 사이트 내용과 기능에 관한 오류를 접수합니다.

접수 범위사이트 오류업체 상담안 함

접수할 수 있는 내용

  • 견적 용어가 잘못된 표준 공종으로 분류된 경우
  • 계산식·합계·상태 판정이 화면 설명과 다르게 동작하는 경우
  • 공공 데이터 출처·기준일·사용범위 설명이 잘못된 경우
  • 내부링크·모바일 화면·인쇄 결과가 깨지는 경우
업체 추천, 견적 의뢰, 공사 중개, 계약 분쟁 상담은 접수 대상이 아닙니다. 실제 견적서를 첨부할 때는 이름·전화번호·주소·업체명 등 개인정보를 제거해 주세요.

접수 경로

현재 공개 저장소의 Issues를 정정·오류 접수 창구로 사용합니다. 제목에 `인테리어 견적`을 포함하고, 문제가 발생한 페이지와 재현 방법을 적어 주세요.

GitHub Issues에 제보변경이력 확인데이터 기준 확인

정정 처리

오류가 확인되면 계산식·표현·출처 설명을 수정하고 사용자 판단에 영향을 주는 변경은 변경이력에 날짜와 이유를 남깁니다.
