개인정보처리방침

견적 입력값은 현재 서버로 전송하지 않고 브라우저 저장공간을 사용합니다. 오류 제보 등 외부 접수 시에는 사용자가 직접 제공한 정보만 해당 서비스의 정책에 따라 처리됩니다.

적용일2026-09-11견적 입력브라우저 저장서버 전송기본 없음

1. 견적·도구 입력

견적서 검사, A/B/C 비교, 계산기, 체크리스트의 입력값은 현재 브라우저의 localStorage에 저장됩니다. 사이트가 별도 서버로 견적 내용을 업로드하거나 계정을 만들지 않습니다.

공용 기기에서는 브라우저 저장값이 남을 수 있으므로 사용 후 초기화하거나 아래 로컬 데이터 관리 기능으로 삭제해 주세요. 메모 칸에는 이름, 전화번호, 주소, 업체 담당자 이름 같은 개인정보를 적지 않는 것을 권장합니다.

2. 오류·정정 요청

오류 제보는 외부 GitHub Issues를 이용할 수 있습니다. 이 경우 GitHub 계정정보와 사용자가 직접 작성한 내용은 GitHub의 서비스 정책에 따라 처리됩니다. 견적서 이미지를 올릴 때는 개인정보와 업체 식별정보를 제거해 주세요.

3. 쿠키·브라우저 저장

현재 견적 기능은 로그인 쿠키 대신 localStorage를 사용합니다. 브라우저 또는 호스팅 플랫폼이 서비스 제공과 보안을 위해 별도의 기술 정보를 처리할 수 있습니다.

견적검수실 도구가 직접 만든 저장키는 interior-v6- 접두사로 제한합니다. 아래 삭제 기능도 이 접두사의 키만 대상으로 하며 같은 도메인의 다른 저장정보를 임의로 지우지 않습니다.

내 브라우저 저장 데이터

저장된 값의 실제 내용은 서버로 보내지 않고 이 브라우저 안에서만 개수와 대략적인 용량을 계산합니다. 삭제 버튼은 견적검수실의 interior-v6-* 키만 제거합니다.

대략 용량확인 중

4. 광고 기능

현재 v6 검수판에는 광고 코드를 넣지 않습니다. 운영판에서 Google AdSense 등 광고 기능을 사용하는 경우 Google과 광고 파트너가 광고 제공·빈도 제한·측정을 위해 쿠키 또는 유사 기술을 사용할 수 있으며, 실제 적용되는 광고 서비스와 선택 해제 안내를 이 방침에 명확히 표시합니다.

5. 보관과 삭제

localStorage의 견적 데이터는 사용자의 브라우저에 남습니다. 각 도구의 초기화 기능, 위의 견적검수실 저장값 삭제 기능 또는 브라우저의 사이트 데이터 삭제 기능으로 지울 수 있습니다. 사이트 서버에 별도 보관된 견적 입력값은 현재 없습니다.
