욕실과 주방은 범위·수량·사양이 없고, 폐기물과 VAT는 총액에 포함됐는지 알 수 없습니다.

1. 공종명을 표준 항목으로 옮깁니다

업체마다 같은 공사를 다른 이름으로 적습니다. ‘화장실’, ‘욕실공사’, ‘욕실 1식’은 우선 욕실이라는 같은 공종으로 묶고, 세부 범위를 다시 확인합니다.

2. 수량과 단위를 봅니다

금액이 있어도 수량이 없으면 단가를 비교할 수 없습니다. 욕실은 개소, 주방은 길이, 샷시는 창 개수·치수, 바닥은 면적처럼 공종마다 비교 단위가 다릅니다.

  • 욕실: 욕실 수, 타일 범위, 배관 이동 여부
  • 주방: 상·하부장 길이, 상판 길이, 아일랜드 여부
  • 샷시: 창 개수, 가로×세로, 유리 사양
  • 도배·바닥: 실제 시공면적, 기존 마감 철거 여부

3. 사양을 맞춥니다

같은 공종·같은 수량이어도 자재와 공법이 다르면 금액 차이는 정상일 수 있습니다. 사양이 없는 견적은 ‘비쌈/쌈’보다 ‘비교 불가’로 두는 편이 안전합니다.

4. 별도와 미기재를 구분합니다

‘별도’는 견적서에서 제외됐다고 적힌 상태이고, ‘미기재’는 포함인지 제외인지 문서만으로 판단할 수 없는 상태입니다. 두 상태를 0원으로 처리하면 총액 비교가 틀어집니다.

5. 총액은 마지막에 봅니다

공종·수량·사양·포함조건이 맞은 뒤에야 총액 차이가 의미를 가집니다. 조건이 다르면 먼저 차이를 표시하고, 조건이 같은 항목만 금액을 비교합니다.
