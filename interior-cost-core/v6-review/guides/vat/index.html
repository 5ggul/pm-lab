VAT 별도 견적 해석

A 견적은 VAT 포함, B 견적은 별도라면 표시 총액만으로 비교하지 않습니다. 두 견적을 같은 표시 기준으로 맞춘 뒤 공종 차이를 봅니다.

다른 견적도 같은 기준인지 확인합니다.

별도
표시 총액 밖에 따로 계산되는 상태

표시 총액만 놓고 포함 견적과 비교하지 않습니다.

미기재
견적서만으로 포함 여부를 판단할 수 없는 상태

업체 확인 전에는 비교값으로 고정하지 않습니다.

총액 정규화 순서

  1. 각 견적의 VAT 상태를 표시합니다.
  2. 폐기물·샷시·현장관리비도 같은 방식으로 포함조건을 적습니다.
  3. 상태가 다른 견적은 ‘조건 불일치’로 먼저 표시합니다.
  4. 같은 기준으로 맞춘 뒤에만 공종별 금액 차이를 봅니다.
미기재를 임의로 포함 처리하지 않습니다

문서에 없는 조건을 추정해서 총액을 보정하면 비교 결과가 실제 견적과 달라질 수 있습니다.
