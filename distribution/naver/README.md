# 네이버 블로그 검토용 초고

이 폴더의 8개 글은 공개 사이트가 아닌 로컬 배포 초고입니다. 자동 발행하지 않습니다. 게시 직전 최신 사이트 산출물로 다시 생성하고 사양·단위·조건·문장을 수동 검토하세요. 검색 노출·순위를 보장하는 자료가 아닙니다.

생성: `node docs/car-data-preview/scripts/build-search-distribution.mjs`

현재 원문과 초고 일치 검사: `node docs/car-data-preview/scripts/build-search-distribution.mjs --check`

가변 금액은 실제 생성 HTML의 표시값에서만 인용합니다. HTML에서 근거를 추출할 수 없으면 생성이 실패하며 임의 계산으로 대신하지 않습니다. 이 생성기를 실행해도 사이트 HTML·정책·사이트맵은 바뀌지 않습니다.
