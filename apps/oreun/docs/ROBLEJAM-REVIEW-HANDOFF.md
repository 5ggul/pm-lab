## 이번 변경
공개 헤더·푸터·로그인/오류/탈퇴 안내·정책 페이지·메타데이터·구조화 데이터·OG 이미지 문구의 오름 표기를 로블잼으로 변경했다. 소스 검사와 타입/단위 검사를 실행했다. 신규 커밋의 전체 프리뷰/브라우저 검증은 해당 커밋 실행 결과로 확인해야 한다.

기존 oreun 기술 경로, URL, 세션 쿠키, 초안 키, DB 식별자, OAuth callback, 패키지명은 유지했다. 이용자 게시글이나 기존 공략 DB 원문을 일괄 치환하지 않았다. Google Cloud 동의 화면 표시 이름은 별도 설정이며 이번에 바꿨다고 주장하지 않는다. 도메인 구매·상표 등록·공식 제휴·브랜드 사용 허가 확인은 하지 않았다.

## 외부 검수 핵심
실제 프리뷰와 최신 PR HEAD를 함께 확인하고 코드 확인/실제 재현/제안/미확인을 구분한다. 문서의 PASS를 실사용 재현으로 대체하지 않는다.

1. 로블잼 이름 일관성과 375/390/768/1440px에서 긴 로고·메뉴 레이아웃.
2. 밝고 풍성한 화면이 검색·가독성·정보 발견에 도움이 되는지. 실제 게임 이미지·장르·질문·파티 카드의 역할, 중복 카드와 장식의 과잉 여부.
3. 최소 5개 공략의 실제 유용성과 반복 문구, DB/저장소/공개 렌더링 일치. 문체만으로 AI 작성 여부를 단정하지 않고 필요한 조건·출처를 보존한다.
4. 질문/답변/댓글/파티 초안과 재시도·계정상태·데이터 누락·알림 복귀 검토.
5. 탈퇴의 재인증·대상 소유권·실패 처리·다른 이용자 글 보존·세션 종료의 실제 보장 범위.
6. 검색/공유 품질, 첫 질문에 답변이 달리는 구조, 운영 부담, 광고와 어린 이용자 보호.

현재 Google=true, Email=false는 최근 확인 기록이며 외부 검수 시 관측 시점을 구분한다. 답변·댓글·파티 및 탈퇴 폼의 로컬 Chromium/WebKit 검사와 DB rollback 검사는 수행했지만 실제 Google 2계정 통합 E2E, 실기기 아이폰, 실제 테스트용 Google 계정 탈퇴는 아직 별도 확인이다.

이전 세부 기능과 테스트 범위는 YOUTH-EXPERIENCE-AND-ACCOUNT.md 참고. 이번 브랜딩 작업은 신규 게임 사실의 검증이나 공략 원문 전면 재작성과 다르다.

피드백 전용 검수자는 코드·DB·계정·알림·게시물·신고·권한을 변경하지 않는다. 이름이 변경되었다고 연령 제한을 낮추거나 oreun 기술 키를 변경하지 않는다. 만 14세 이상 커뮤니티 작성 제한, noindex, Draft/Open을 유지한다. 정식 공개·운영 도메인·Search Console·AdSense는 별도 승인이다.
