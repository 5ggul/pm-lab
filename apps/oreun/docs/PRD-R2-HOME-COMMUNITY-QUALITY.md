# 로블잼 R2 홈·커뮤니티 품질 고도화 PRD

기준일: 2026-09-25  
대상: `apps/oreun/`  
목표: 승인 시안 수준의 첫인상, 최신 데이터 탐색, 글쓰기 활성화, 사용자 공략 생산, 안정적인 프로필 수정

## 1. 홈 히어로
- 좌/우 패널처럼 보이는 세로 경계선을 제거한다.
- 마스코트·배경은 한 장의 고해상도 통합 비주얼을 사용하고 텍스트/CTA만 접근 가능한 DOM 레이어로 유지한다.
- `자유 톡 가기`는 360px 이상 모든 검수 폭에서 한 줄이어야 한다.
- 주 CTA와 보조 CTA는 명확한 대비, hover/focus 상태, 충분한 터치 영역을 가진다.
- 360/375/390/430/768/1024/1264/1440에서 가로 overflow 0.

## 2. 비교
- 비교의 주인공은 수치다. 게임 사진은 소형 썸네일만 사용한다.
- 2~4개 비교에서 표 자체가 viewport를 강제로 넓히지 않아야 한다.
- 모바일은 이미지를 숨기거나 매우 작게 표시하고 이름·수치 가독성을 우선한다.

## 3. 상승 중
- `force-dynamic` + 최신 hourly rollup을 사용한다.
- 실제 양의 모멘텀 결과는 Trend Engine 점수순으로 정렬한다.
- 판정 가능한 상승 게임이 없으면 빈 화면 대신 현재 플레이 인원이 확인되는 인기 게임을 별도 fallback 라벨로 보여준다.
- fallback을 상승 결과로 오인시키는 문구/배지는 금지한다.
- 홈과 `/rising`은 같은 원천과 동일한 상승 판정 원칙을 사용한다.
- 최신 데이터 기준시각을 화면에 노출한다.

## 4. 내 정보
- handle / 표시 이름 / 소개를 단독 또는 동시에 수정할 수 있어야 한다.
- authenticated 사용자에게 `profiles(handle, display_name, bio)` UPDATE 권한과 RLS 소유권 검사를 함께 적용한다.
- handle 중복·형식 오류·금지 연락처 오류는 원문 DB 오류 대신 사용자용 메시지를 표시한다.
- 성공 후 새로고침해도 값이 유지된다.

## 5. 자유 톡
- 전체 자유글 작성 폼은 최근 글 목록 아래에 둔다.
- `첫 자유글 쓰기`는 `?write=1#write`로 이동해 하단 작성 영역을 열린 상태로 보여준다.
- 게임 연결이 없는 글은 모든 최근 글 카드에서 `자유게시판` 라벨을 표시한다.

## 6. 유저 공략
- 로그인한 활성 일반 사용자가 공략을 작성할 수 있다.
- 입력: 게임, 유형, 제목, 본문.
- 유저 공략은 공식 편집 공략과 분리된 `COMMUNITY_UGC` 흐름으로 저장한다.
- 공개 피드/게임별 공략 페이지/상세 페이지에서 작성자와 `유저 공략` 표기를 보여준다.
- RLS, 요청 UUID idempotency, rate limit, 금지 연락처 검사, 작성자 소유권 보호를 적용한다.

## 7. 공짜 혜택
- 사용자 노출 명칭은 `공짜 혜택` 중심으로 유지한다.
- 상단 설명은 정확히: “공식 게임 설명·공식 개발자 출처에서 직접 확인한 무료 보상 코드만 공개합니다.”
- “아무 보상 코드나 채워 넣지 않습니다.” 정책 카드와 장문의 방어 문구는 제거한다.
- 보상 코드 복사와 Roblox 이동 CTA를 유지한다.

## 9. 커뮤니티 게임 선택 확장
- 자유 톡·유저 공략 작성에서 게임 선택 UI는 고정 20~30개 `<select>`에 묶이지 않는다.
- Roblox 공식 추천 결과를 기반으로 커뮤니티 선택용 카탈로그를 100개 이상 유지한다.
- 새 카탈로그 게임은 `collecting` 상태로 추가해 검색/선택에는 노출하되, 출시 색인 품질 게이트의 26개 curated launch set과 분리한다.
- 게임 선택기는 검색형 UI로 제공하며 게임명·영문명·alias를 검색할 수 있어야 한다.
- 일반 자유글은 게임을 선택하지 않고 `자유게시판`으로 남길 수 있어야 한다.
- 공략 작성은 게임 선택이 필수이며, 서버 검증에서 최종적으로 다시 확인한다.
- 카탈로그가 100개를 넘더라도 thumbnail/history read가 URL 길이·요청 제한 때문에 실패하지 않도록 batch 처리한다.

## 10. 자유 톡 상단 비주얼
- 단색/단순 그라데이션 네모 박스를 금지한다.
- 승인된 로블잼 3D 톤의 전용 배너 이미지를 사용하고 텍스트는 DOM 레이어로 유지한다.
- 배경 이미지 위에도 제목·설명 대비가 충분히 확보되도록 어두운 왼쪽 overlay를 사용한다.
- 모바일에서는 이미지 포커스를 조정하되 텍스트가 캐릭터·썸네일 위에 겹쳐 읽기 어려워지지 않아야 한다.
