# Page generation / index / ad policy

These are internal quality gates, not Google-stated minimum numbers.

## Page may exist but remain noindex
- search results and query/filter variants
- date-specific flight instances
- airport departure/arrival/irregular subpages without enough live rows
- flight-number hub without meaningful history
- route page without enough observed days/flights
- capability page/module backed by stale or absent official data

## Airport main index candidate
Requires live-verified source, visible source/freshness, current sample, recent-four-week baseline sample, enough flight rows and a unique comparison value.

## Flight-number hub index candidate
Requires a valid route, current/schedule data and a minimum recent-history sample. Do not pre-generate every flight number.

## Route index candidate
Requires a valid route and sufficient observed days/flights. Start with manually reviewed major routes only.

## Ad eligibility
Stricter than indexability: trust pages must be complete, preview/mock markers removed, no empty modules, and production data must be live. The current Preview is not AdSense-ready.
