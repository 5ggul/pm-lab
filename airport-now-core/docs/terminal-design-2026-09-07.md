# 공항나우 공항 디자인 · 2026-09-07

## 방향
밝은 아이소메트릭 공항 모형, 파란 유리 터미널과 청록색 조명을 첫 화면의 시각적 중심으로 사용한다. 검색 다음에는 출발·도착을 구분한 남색 전광판을 제공한다.

## 적용
- 홈: 공항 일러스트, 편명·공항 검색, 주요 공항 바로가기와 도구 안내
- 공통: 비행기 브랜드 표시, 파란 탐색·버튼, 밝은 안내문과 남색 운항 보드
- 전국 요약: 연속된 전광판 행. 모바일에서는 공항별로 출발·도착을 나란히 표시
- 움직임: 첫 화면 등장 및 링크 반응. 움직임 줄이기 설정에서는 제거

## 이미지
`docs/airport-now-preview/assets/airport-diorama.webp`는 이 프로젝트를 위해 생성한 공항 모형 일러스트다. 사용자가 제공한 동영상의 질감과 색을 참고했으며 원본 영상, 영상 속 로고와 항공사 표식을 서비스에 포함하지 않았다. 실제 공항 배치나 시설 안내도가 아니다. 1536×1024, 약 102 KiB의 WebP로 저장했다.

## 확인
375·390·1440px 홈에서 이미지 로딩과 가로 넘침을 확인했다. 공통 디자인은 홈·인천·제주·항공편 검색·마중 도구·가이드·전국 지연 7개 페이지에서 375·1280px 가로 넘침이 없음을 확인했다. 모바일 메뉴 열림과 제주 검색 결과도 확인했다. 기존 데이터 갱신과 오래된 자료 차단 기능은 유지한다.
