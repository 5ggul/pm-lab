# 순위 사진과 비교 시각화

## 범위

- 휘발유·하이브리드·전기차 순위의 54개 항목에 기존 상업적 이용 가능 이미지 연결. 대표 사진임을 표시하고 저작자·라이선스 링크 유지.
- 순위 수치와 막대는 동일한 공식 사양 행을 사용. 전체 목록에 공통 0 기준 축 적용.
- 10개 정적 비교에 복합연비/전비 막대와 연 2만km 자동차세·에너지비 구성 그래프 제공.
- 직접 비교와 투싼 등 5개 비교 계산기는 입력 결과에 맞춰 비용 구성을 갱신. 누락·잘못된 입력 시 그래프 숨김.
- 서로 다른 km/L와 km/kWh는 공통 연비 축에 올리지 않음. 원화 비용만 비교.
- 숫자·고정 예시·사진은 JavaScript 없이도 HTML에서 읽을 수 있음.

## 검증

- metric-visuals-qa: 320/390/1280px, 사진 매핑·라이선스·로컬 파일 로딩, 0 기준 막대 비율, 비용 산식 일치, 입력 변경·누락·단위 혼합, no-JS, 전체 사진 장애.
- 기존 전체 UI/데이터 검사 유지. 신규 검사를 GitHub 필수 검사에 추가.
- 도메인 및 noindex 설정은 그대로 유지.
