# 내차데이터 남은 작업과 화면 개편

2026-09-08 사용자 승인: 콘텐츠 고도화와 남은 작업 수정, 페이지별 시각 디자인을 완료한다. 도메인 연결·색인 공개는 제외한다.

## 디자인 기준

흰색과 짙은 먹색, 절제한 파란색을 사용하고 차량 사진·차종명·계산 결과가 먼저 읽히는 자동차 전문 매체의 화면으로 만든다.

홈은 사진과 검색, 차량 찾기는 필터와 사진 목록, 상세는 대표 차량과 사양별 비용 해설, 비교는 같은 행에서 읽는 숫자, 순위는 순번과 조건, 리콜은 날짜·대상·조치의 구분을 중심으로 구성한다. 가이드와 고지는 본문 읽기에 집중한다. 서로 다른 목적에 같은 카드 격자를 반복하지 않는다.

필터 선택과 미리보기 전환은 짧게 연결하고, 상세의 목차는 현재 읽는 위치를 돕는다. 움직임 감소 설정을 존중한다. 장식용 움직임이나 가짜 데이터는 추가하지 않는다.
