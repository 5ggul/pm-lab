# 싸그리 기존 자동화 적용 — 2026-10-14
> 후속 사용자 지시로 발행량·시간표 기준은 `QUALITY-LED-VOLUME.md`로 변경됐다. 아래 5건/5회 보존 기록은 첫 적용 시점의 이력이며 현재 설정이 아니다.


사용자 요청: Work에서 이미 돌리던 자동화에 검토한 변경을 적용한다. 별도 자동화나 예약을 만들지 않는다.

## 적용 원본과 실행 경로

원본은 `5ggul/pm-lab`의 `main`, 모듈은 `ops/daangn-cloud`다. 기존 `.github/workflows/daangn-cloud.yml`과 Cloudflare `ops/daangn-clock`은 이 원본을 사용한다. PC의 이전 `dealops-cloud-cutover` 체크아웃은 오래된 커밋이므로 운영 배포본의 근거로 사용하지 않는다.

## 이번 변경과 함께 main에 반영되는 범위

1. 생성 본문은 '할인 기한'을 사용하고 삭제 요청한 최저가 미확인 문장을 다시 쓰지 않는다. 원문 조건은 별도로 보존한다.
2. 제목은 가격·구성·쿠폰 조건을 남기며 줄인다. 완성 문장을 substring으로 잘라내지 않는다. 표시 목표 50자는 내부 보수 기준이며 실제 입력란 maxlength를 다시 검사한다.
3. 명시적인 증정 조건은 상품명에서 분리해 본문에 보존한다. 기재 수량을 무조건 합쳐 계산하지 않는다.
4. 배송 합계 null을 0원으로 출력하지 않는다. 날짜만 있는 기한에 임의 종료 시각을 만들지 않는다.
5. 게시판, 입력란 제목, 본문 입력 결과를 제출 전에 대조한다. 저장 후 제목·본문·게시판·사진 수·게시 URL·게시 시각을 확인한다.
6. 저장 결과 불일치는 publish_unknown으로 남기고 기존 예약 원장이 재발행을 막는다.
7. 새 발행 기록에 기한·검증 지문을 보존하고 기존 보고서에 기한 재검토 목록을 추가한다. 실제 기존 글 수정은 하지 않는다.
8. 이 디렉터리의 AGENTS.md에 사용자 문체·작업 경계·운영 보존 지침을 기록한다.

## 변경하지 않는 것

기존 enabled=true, 하루 최대 5건, KST 09/12/15/18/21시 슬롯, 품질 하한, GitHub 예약, Cloudflare clock, 수집원, 인증, 예약·발행 원장은 바꾸지 않는다. heartbeat도 수정하지 않아 변경 적용을 위해 시험 글을 강제로 발행하지 않는다.

검토 패키지의 전체 자동 발행 중단 정책과 강제 수동승인 기본값은 운영에 복사하지 않는다. 이미지 사용권 원장·다중 이미지 업로더·새 검토 UI는 미검증 운영 변경이므로 이번 배포에서 제외한다. 기존 상품 사진 처리의 권리가 자동으로 새로 검증됐다는 뜻이 아니다.

## 검증

변경 코드에서 `npm run check` 통과: 기존 회귀 테스트 파일 10개와 새 운영 통합 테스트 24건, 실패·건너뛰기 0건. 새 검사는 실제 생성·조건검수·예약·공개 파서·저장결과 모듈을 합성 입력으로 연결한다. 실제 카페의 새 글 발행이나 사진 업로드 성공 시험은 아니다.

## 운영 관측과 되돌리기

다음 기존 실행이 main을 checkout하면서 변경 코드를 사용한다. 코드 병합과 실제 예약 실행·게시 성공은 구분해서 확인한다. 예상치 못한 차단은 원장과 실행 로그에서 사유를 읽으며, 같은 글을 반복 제출하지 않는다.

롤백은 이 적용 커밋을 되돌리는 변경만 만든다. 과거 저장된 publish_unknown·published 기록을 지우지 않는다. 다른 프로젝트·예약·Cloudflare Worker를 함께 되돌리지 않는다.
