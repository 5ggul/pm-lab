# v4 적용 범위와 검증 기록

작성: 2026-09-26. 기존 v3 코드에 다음 기능을 구현했다. PRD의 8주 성장 실험이 완료됐다는 의미는 아니다.

## 적용 기능

- 주제 평가와 근거·독자 필요·편집 관점·공유 대상·연재 목적 기록.
- 최근 20개 글의 카테고리 비중, 같은 주제 연속 금지, 판매처별 일일 상한.
- 전국 공통 정보원 4개: 책이음, 공유누리, 참가격, K-MOOC. 검토한 사실과 조건을 원문에서 재확인.
- 동일 제품·수량·배송 포함 가격이 검증된 후보의 단가 비교. 금요일에는 적격 정보 3개 이상이 있을 때 모음 생성.
- 회원 제보의 동의·승인·근거가 있는 candidate 입력 경로. 아직 실제 회원 제보 데이터는 없다.
- 필수 조건·근거 누락과 미치환 예시 차단, 기존 v3 문장·중복 QA 유지.
- 6개 편집 슬롯·하루 최대 6건·슬롯당 최대 1건. 품질 부족을 백업이 보충하지 않음.
- 발행 전 GitHub에 예약 원장 저장. 불명확한 발행은 재시도하지 않음. 성공한 기록은 원장에서 복구 가능.
- 미검증 비교가격·고정 날짜 추론 차단, 원문 재확인, 이미지 권한 확인 시에만 업로드.
- 학습의 결측·역행·실패 처리, 동일 관측 구간 비교, 서로 다른 글 20개·7일 이상 표본 기준.
- 조회수·댓글과 회원가입·공유·재방문을 분리한 성장 보고서. 회원 수 수동 관측 입력 도구.

## 검증

- `npm run check`: 기존 카피 회귀 검사, 학습 회귀 검사, v4 출처·지역·만료·조건·예약·실패·결측 검사 통과.
- 예약 저장 실패 시 발행 함수가 호출되지 않음, 제출 후 타임아웃은 `publish_unknown`, 다음 슬롯 중복 게시 차단을 주입 테스트로 확인.
- 실제 `npm run preview`: 수집 16건(핫딜 6·정책 6·공공서비스 4) 중 공공서비스 4개 초안이 생성·검수 통과. 미확인 가격과 정책 조건은 검토 대상으로 분리.
- 프리플라이트 반복 테스트는 합성 입력 검증이다. ‘서로 다른 실제 초안 30개를 사람이 전수 검수했다’는 의미가 아니다. 실제 새 유형 검수 표본은 현재 공식 서비스 4개다.
- 게시를 일으키는 로컬 테스트는 실행하지 않았다. CI 검증 및 운영 반영 상태는 PR과 Actions 실행 결과로 확인한다.

## 운영상 남아 있는 항목

- 지역 미지정: `primaryRegions:[]`. 전국 공통 정보부터 운영하고 지역 행사 발행은 보류.
- 소개·고정글 문안은 `COMMUNITY-GROWTH-ASSETS.md`에 준비됨. 이 구현은 당근 관리 화면의 소개·고정글을 변경하지 않는다.
- 공유·저장·회원별 재방문·가입 귀속은 플랫폼 제공 여부 미확인. 자동 측정을 구현한 것으로 표시하지 않음.
- 수동 검수·회원 질문에 대한 운영자 응답·유입 채널 협업은 별도 운영 작업. 대량 홍보·자동 DM·자동 댓글은 없음.
- 공식 서비스 4개는 매번 새로운 주제가 생성되는 무한 수집원이 아니다. 동일 안내 반복 발행을 막으며, 신규 서비스는 원문 검토 후 registry에 추가해야 한다.
- 단가 비교·정보 모음은 조건을 충족한 데이터가 있을 때 동작한다. 현재 미리보기에서는 검증된 비교 쌍이 없어 비교 글을 만들지 않았다.
- 기존의 추정 가격 후보는 통과하지 못할 수 있어 당분간 발행량이 감소할 수 있다. 품질 기준을 낮춰 숫자를 채우지 않는다.
- 정정 대상의 자동 탐지·원문 자동 수정, 회원별 유지율 수집, 실험 무작위 배정·통계 보고는 후속 구현 항목이다. 이번 변경에 포함됐다고 주장하지 않는다.

## 되돌리기

즉시 발행 정지가 필요하면 `growth-config.json`의 `enabled`를 false로 변경한다. 소스·비교·모음·회원 제보는 `features`의 해당 값으로 개별 중지할 수 있다. 기존 발행·예약 원장을 삭제하지 않는다. 이전 엔진으로 회귀할 때도 `publishing`/`publish_unknown` 원장을 먼저 확인해야 하며, 미확인 글을 재발행하지 않는다.
