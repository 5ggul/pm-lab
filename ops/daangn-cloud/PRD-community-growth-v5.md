# 싸그리 Community Growth Engine v5 PRD

Status: implementation target
Date: 2026-10-06
Scope: 당근 카페 자동 수집·카피·선정·발행·학습

## 1. 문제 정의

현재 시스템은 사실 검증과 중복 방지는 강하지만 피드 경험에 두 가지 문제가 있다.

1. 본문 구조가 반복된다.
   - 상품명·총액·단가
   - 기준가·할인액·할인율
   - 배송·쿠폰·행사기한
   - 구매 전 확인할 한마디
   - 링크

   상품이 달라도 이 순서가 반복되어 사람이 연속으로 읽으면 자동 생성 흔적이 보인다.

2. 공급 포트폴리오가 할인상품에 치우쳤다.
   - 하루 상업성 글 상한이 일일 전체 상한과 같았다.
   - 공공서비스와 검증된 공식 생활정보 수집기가 구현돼 있지만 운영 경로에서 비활성화돼 있었다.
   - 조회수 최적화가 피드 다양성보다 우선하면 할인글만 계속 선택될 수 있다.

## 2. 제품 목표

- 하루 5개 발행 기준 상업성 게시물은 최대 3개다.
- 하루 최소 목표 2개는 비상업성 생활정보다. 공급이 부족하면 억지 글 대신 총 발행량을 줄인다.
- 상업성 게시물이 3개 연속 나오지 않는다.
- 동일 본문 레이아웃은 최근 4개 게시물 안에서 반복하지 않는다.
- 같은 가격 설명 순서는 최근 6개 상업성 글 안에서 반복하지 않는다.
- 최근 20개 게시물을 제목 없이 읽어도 같은 템플릿이 반복된다는 인상을 주지 않아야 한다.
- 모든 비상업성 정보는 공식 원문과 문장별 근거를 가져야 한다.

## 3. 콘텐츠 포트폴리오

### 3.1 상업성

- CURRENT_OFFER: 현재 결제가와 조건이 확인된 상품
- PRICE_DROP: 기존 관측 대비 실제 가격 하락
- UNIT_VALUE: 묶음 수량과 단가가 구매 판단의 핵심인 상품
- VERIFIED_COMPARISON: 동일 상품·옵션·배송 조건을 검증한 비교

### 3.2 비상업성

- VERIFIED_BENEFIT: 환급·통신비·전기요금 등 공식 혜택
- PUBLIC_SERVICE: 도서관·공공시설·공공 가격정보·무료교육 등 공식 서비스
- HOUSEHOLD_BRIEF: 정부·공공기관 원문에서 현재 행동 가능한 생활정보만 별도 검토한 글
- UTILITY_DIGEST: 서로 다른 공식 생활정보 3개를 주 1회 이하로 묶은 글

### 3.3 자동 발행 제외

- 일반 뉴스 요약
- 정치·투자·대출 권유
- 의학적 판단
- 확인되지 않은 지역 행사
- 개인 경험을 꾸민 글
- 단순 상식·생활꿀팁을 출처 없이 만든 글
- 댓글 유도만을 위한 질문 글

## 4. 하루 구성

기본 슬롯:

- 09시: 생활정보 우선
- 12시: 할인상품 우선
- 15시: 생활정보 우선
- 18시: 할인상품 우선
- 21시: 당일 부족 포트폴리오 보충

하드 규칙:

- dailyMax = 5
- commercialDailyMax = 3
- utilityDailyTarget = 2
- maxConsecutiveCommercial = 2
- 동일 카테고리 일일 상한 유지
- 적격 비상업성 후보가 없으면 할인상품으로 무조건 대체하지 않는다.

## 5. 공급 파이프라인

### 5.1 공식 서비스

`source-registry.json`의 검토된 서비스 페이지를 매일 재확인한다.

필수 조건:

- 등록된 공식 URL과 동일 호스트
- 사전 검토한 evidence 문자열 모두 존재
- facts와 conditions가 그대로 유지
- 발행 직전 원문 재확인

### 5.2 공식 생활정보 리서치

정부 정책브리핑에서 생활비·무료·환급·통신·교육·돌봄·소비자 관련 후보를 찾는다.

- 기사 원문은 120일 이내
- 문장별 evidence가 원문에 그대로 존재
- 별도 AI 편집과 독립 검토를 모두 통과
- 사실 2~4개, 조건 최대 3개
- 발행 직전 원문 해시 재확인
- 원문이 바뀌면 자동 폐기

### 5.3 할인상품

현재의 가격·통화·옵션·쿠폰·배송·기한·상품 동일성 검증을 유지한다.

## 6. 본문 레이아웃 엔진

단어 랜덤 치환이 아니라 정보의 순서와 문단 역할을 바꾼다.

### 6.1 상업성 레이아웃 패밀리

- PRICE_THEN_TERMS: 총액·단가 → 할인·배송·조건 → 구매 판단
- TERMS_THEN_PRICE: 쿠폰·배송·기한 → 총액·단가 → 비교가격
- SAVING_FIRST: 가격 차이·할인율 → 총액·단가 → 배송·조건
- UNIT_FIRST: 단가 → 총액 → 할인·배송 → 보관/소비 판단
- FIT_FIRST: 수량·보관·소비 조건 → 총액·단가 → 할인 조건
- HISTORY_FIRST: 최근 관측/가격하락 → 현재 총액 → 배송·조건
- DELIVERY_FIRST: 배송 포함 금액 → 상품가·단가 → 할인·조건
- COMPACT_FACTS: 짧은 사실 3~5줄 → 링크
- TWO_PARAGRAPH: 구매 판단 문장 → 가격·조건을 한 문단으로 정리
- CONDITION_WRAP: 조건 → 가격 사실 → 마지막 주의점

모든 레이아웃은 검증된 필수 가격 문구와 조건을 누락하지 않는다.

### 6.2 생활정보 레이아웃 패밀리

- FACT_FIRST: 사실 → 조건 → 공식 링크
- CONDITION_FIRST: 대상/제외조건 → 사실 → 링크
- ACTION_FIRST: 어디서 무엇을 할 수 있는지 → 조건 → 링크
- WHO_FIRST: 대상자 → 받을 수 있는 내용 → 신청/이용 조건
- TWO_STEP: 첫 단계 → 다음 단계 → 주의사항
- SHORT_GUIDE: 핵심 사실 2개를 한 문단 → 조건 별도 → 링크
- SPLIT_FACTS: 사실별 짧은 문단 → 조건 → 링크
- SOURCE_MIDDLE: 사실 → 공식 링크 → 조건
- CONDITION_WRAP: 조건 → 사실 → 마지막 제한사항
- MINI_CHECK: 대상·내용·주의를 서로 다른 문장 길이로 배치

## 7. 반복 탐지

게시물마다 다음을 저장한다.

- contentKind
- layoutFamily
- styleMode
- titleStrategy
- skeleton
- paragraphCount
- paragraphLengthPattern
- sentenceLengthPattern
- openingKey
- closingKey
- linkPosition
- CTA 여부
- 질문 여부

하드 게이트:

- 동일 layoutFamily 최근 4개 내 재사용 금지
- 동일 skeleton 최근 8개 내 재사용 금지
- 동일 openingKey 최근 20개 내 재사용 금지
- 동일 closingKey 최근 15개 내 재사용 금지
- 같은 문단 길이 패턴 3개 연속 금지
- 같은 콘텐츠 종류 3개 연속 금지
- 상업성 콘텐츠 3개 연속 금지

소프트 패널티:

- 같은 제목 전략 최근 5개 내 사용
- 같은 링크 위치 4개 연속
- 같은 문장 수 4개 연속
- 같은 종결 리듬 최근 20개 내 사용

## 8. 제목 원칙

상업성 글 제목은 아래 중 하나를 선택한다.

- 상품명 + 현재 결제가
- 현재 결제가 + 상품명
- 상품명 + 단가 + 총액
- 할인액/할인율 + 상품명 + 결제가
- 배송 포함 금액 + 상품명
- 실제 가격하락 + 상품명
- 독자 상황 + 상품명 + 결제가

비상업성 제목은 원문 제목을 그대로 복사하지 않고, 검증된 사실 중 독자가 행동할 이유가 되는 한 가지를 제목으로 쓴다. 단, 자동 과장과 가짜 긴급성은 금지한다.

## 9. 커뮤니티 말투

- 친근하지만 설명하려 들지 않는다.
- 애교 어미 자동 사용은 기본 0회다.
- 질문은 최근 10개 중 최대 1개다.
- `참고하세요`, `확인하세요`, `보세요` 같은 CTA는 최근 5개 중 최대 2개다.
- 가짜 사용·구매·육아 경험은 0건이어야 한다.
- 모든 글을 친절하게 결론 내리지 않는다. 정보가 끝나면 링크에서 끝날 수 있다.

## 10. 이미지

- 상품글은 검증된 실제 상품 이미지 사용
- 공공서비스·공식 생활정보는 이미지 없이 발행 가능
- 카드뉴스·AI 썸네일 자동 생성 금지
- 이미지 유무 자체도 피드 리듬의 일부로 사용

## 11. 학습 시스템

조회수 학습은 콘텐츠 포트폴리오 하드 규칙을 넘을 수 없다.

학습 가능:

- 같은 종류 안에서 제목 전략
- 레이아웃 패밀리
- 링크 위치
- 게시 시간대
- 카테고리 가중치

학습 불가:

- commercialDailyMax
- utilityDailyTarget
- maxConsecutiveCommercial
- 사실·출처·가격 검증
- AI 말투·가짜 경험·과장 금지

## 12. 관측 지표

매일 기록:

- 상업성/비상업성 비율
- 콘텐츠 종류별 발행 수
- layoutFamily 분포
- 최근 20개 동일 레이아웃 재사용 수
- 평균 문단 수와 패턴 분포
- 조회수·댓글·회원 수
- 콘텐츠 종류별 시간당 조회수
- 신규 회원 증가가 발생한 날의 콘텐츠 조합

## 13. 출시 기준

- 회귀테스트 전체 통과
- 공식 서비스 수집·원문 재확인 통과
- 공식 생활정보 리서치 수집·독립 검토 통과
- 상업성 후보 1건에서 실제 레이아웃 8종 이상 생성
- 생활정보 후보 1건에서 레이아웃 8종 이상 생성
- 최근 20개 시뮬레이션에서 동일 layoutFamily 최근 4개 중복 0
- 상업성 3연속 0
- 하루 5개 기준 상업성 최대 3개
- AI 금지 문장 0
- 가짜 경험 0
- 필수 사실·조건 누락 0
- 적격 생활정보가 없을 때 억지 생성 0

## 14. 최종 운영 원칙

싸그리는 할인 전단지가 아니라 생활비와 일상에 바로 쓰는 정보를 골라주는 동네 커뮤니티다.

> 세일은 피드의 일부일 뿐 전부가 아니다.
> 같은 사실이라도 매번 같은 순서로 말하지 않는다.
> 조회수가 높아도 피드가 광고판처럼 보이면 실패다.
> 회원이 다시 들어올 이유가 되는 정보가 매일 섞여야 한다.
