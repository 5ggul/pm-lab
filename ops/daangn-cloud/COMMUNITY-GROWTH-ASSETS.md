# 싸그리 소개·고정글·제보 운영안

상태: 적용 가능한 문안. 카페 소개·고정글 설정은 아직 변경하지 않음.

## 소개문

장보기 할인, 생활비 비교, 알아두면 쓸모 있는 공공서비스를 모아요. 가격만 보지 않고 배송비와 이용 조건까지 확인합니다. 직접 찾은 정보나 궁금한 품목도 편하게 남겨주세요.

## 새 회원 안내

제목: 처음 오셨다면, 관심 있는 생활비부터 골라보세요

싸그리는 생활비를 줄일 때 도움이 되는 정보를 모으는 공간입니다.

- 핫딜 정보: 상품 가격과 배송·할인 조건
- 꿀팁 공유: 장보기 비교, 공공서비스, 생활에 쓰는 정보
- 절약 인증: 직접 해본 절약 방법과 경험
- 환급 질문: 궁금한 조건을 질문하는 공간. 개인별 적용 여부는 공식 안내를 함께 확인해주세요.

관심 있는 품목이나 궁금한 점을 남겨주시면 다음 정보를 고르는 데 참고할게요. 행사·할인 정보가 바뀌었으면 해당 글에 알려주세요.

대표 글 링크는 실제 발행 후 유효한 글 3개를 골라 연결한다. 아직 발행하지 않은 글 URL이나 고정 연재 날짜를 지어내지 않는다.

## 질문 후보 — 자동 등록하지 않음

- 생필품 가격 비교할 때 배송비 때문에 망설였던 품목이 있나요? 상품명만 남겨주셔도 다음 비교 주제를 고르는 데 도움이 됩니다.
- 집에서 가장 자주 사는 생필품은 어떤 건가요? 묶음 수량까지 같이 남겨주시면 단가 비교에 참고할게요.

실제 답변을 검증 큐로 연결하고 후속 정보를 만들 수 있을 때만 질문한다. 최대 주 2회.

## 회원 제보 입력

`state/member-submissions.json`에 기존 candidate 스키마로 저장한다. `consent`, `reviewApproval`, 검증된 `copyContext.claims`, 원문 `recheckEvidence`, 독자 필요·조건을 모두 갖춰야 후보가 된다. 회원 식별 정보는 넣지 않는다. 질문·댓글 자동 게시와 DM 발송은 활성화하지 않았다.

## 성장 지표 입력

회원 수가 실제 화면에서 확인된 경우에만:

```sh
node src/growth-admin.mjs record-members --members 123 --source "카페 관리 화면에서 확인한 총회원 수"
node src/growth-admin.mjs report
```

123은 명령 형식 설명용 예시이며 실제 회원 수가 아니다. 자동화의 Git 저장 상태로 반영하지 않은 로컬 입력은 클라우드에 전달되지 않는다. 접근할 수 없는 공유·저장·가입·재방문 지표는 null로 유지한다.
