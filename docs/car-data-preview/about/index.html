About

차량을 산 뒤에도 다시 보는 정보.

내차데이터는 차량 판매 카탈로그를 복제하는 사이트가 아니라, 특정 차량 사양의 표시연비·자동차세·유류비·리콜 확인 경로를 한곳에 정리하는 데이터 서비스입니다.

무엇을 보여주나

  • 파워트레인·구동·타이어별 정부 신고 연비
  • 최초등록월을 반영한 자동차세 추정
  • 공식 연비와 오피넷 유가를 이용한 연간 유류비
  • 모델 리콜 목록과 개별 차량 리콜 확인 경로의 분리
  • 조건이 같은 두 사양의 1년 비용 비교

무엇을 하지 않나

보험료·중고차 가격·고질병·정비 규격을 추측하지 않습니다. 리콜 대상 여부도 자체 판정하지 않습니다. 공식 원문과 계산 가정을 화면 가까이에 표시합니다.

공식 사이트가 아닙니다

이 사이트는 현대자동차, 국토교통부, 한국에너지공단, 한국교통안전공단, 자동차리콜센터, 한국석유공사의 공식 서비스가 아닙니다. 탑승·정비·리콜 대상 여부는 제조사와 관계 기관의 최신 안내가 우선합니다.
