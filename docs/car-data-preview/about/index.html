내차데이터

차량 판매 카탈로그를 복제하지 않고, 실제 신고 사양의 효율과 세금·에너지비를 같은 조건으로 연결하는 자동차 데이터 서비스입니다.

제공하는 정보

  • 파워트레인·구동·휠·인승·옵션에 따라 달라지는 정부 신고 연비·전비
  • 배기량과 차령 기준의 연간 정상 자동차세 추정
  • 공식 효율과 오피넷 유가 또는 사용자 충전단가를 이용한 연간 에너지비
  • 같은 주행거리·에너지 가격 조건의 차량 비교
  • 모델 리콜 공지와 개별 차량 리콜 확인 경로의 분리

제공하지 않는 정보

Phase 1에서는 보험료·중고차 시세·정비비·고질병·감가상각을 계산하지 않습니다. 차량번호나 VIN을 받아 자체적으로 리콜 대상 여부를 판정하지도 않습니다.

공식 사이트가 아닙니다

이 사이트는 자동차 제조사, 국토교통부, 한국에너지공단, 자동차리콜센터, 한국석유공사의 공식 서비스가 아닙니다. 실제 고지액·리콜 대상·차량 사양은 관계 기관과 제조사의 최신 안내가 우선합니다.
