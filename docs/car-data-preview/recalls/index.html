모델 리콜 공지

리콜 정보

모델에 발표된 공지는 이 페이지에서 확인합니다. 모델 공지가 있다고 해서 내 차량이 반드시 대상인 것은 아닙니다.

리콜 공지 기준

최근 연결 공지

생산기간·세부모델 범위를 확인해야 하며, “관련 모델” 표시는 해당 모델군 전체가 대상이라는 뜻이 아닙니다.

현재 연결된 공지가 없습니다. 이는 리콜이 없다는 뜻이 아닙니다.

내 차가 실제 대상인지

최종 대상 여부는 자동차등록번호 또는 차대번호(VIN)와 생산범위를 대조해야 합니다. 차량번호·VIN은 이 사이트에 입력하거나 저장하지 않습니다.

차량번호·VIN 공식 확인

모델 리콜은 우리 사이트에서 제공하고, 개별 차량 판정은 공식 조회가 우선입니다.

정보 갱신

공식 자료를 기준일별 반영

공식 공개 공지를 확인해 반영하며, 자동차리콜센터 공식 API 사용 승인이 완료되면 같은 화면을 자동 동기화 데이터로 전환할 수 있게 설계했습니다.
