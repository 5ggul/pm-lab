# Clear UI and scoped rankings — 2026-09-06

The home page now provides search, three efficiency lists, six reviewed model entries, five exact-variant comparisons and recent recall links. Removed repetitive generated copy and the VIN confirmation blocks requested by the user. Recall search uses ordinary empty-search wording; it does not state that the vehicle has no recalls.

Catalogue filters and results have separate regions. Extra brand/class filters collapse on mobile. Cards show official efficiency ranges by fuel and identify them as ranges across registered variants. Family pages separate source-backed specs from expandable generation lists. Long calculation scope remains available in disclosures.

Rankings are deliberately restricted to reviewed family identities with passenger classification, known fuel and usable positive combined efficiency. They select one maximum per family for gasoline, hybrid or electric; equal values share rank. The raw variant name, record link, snapshot date and inclusion of older model years are visible. This is not a new-car market-wide ranking. No SUV ranking is published with the current three reviewed body-style records.

Added Grandeur gasoline/hybrid and K8 gasoline/hybrid comparisons using existing reviewed same-drive/same-wheel variants. The total is five comparisons, not the proposed 20–30. No new vehicle specifications, unverified model promotions, made-up readership scores or approval guarantees.

Validation includes source maxima, family coverage, tie ranking, four-width browser navigation/search/filter/generation tests, forbidden copy checks and existing calculator/photo regression suites. All pages remain noindex. Production, domain, robots policy and AdSense activation are unchanged.
