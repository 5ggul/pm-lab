개인정보 처리 원칙

현재 검수용 페이지는 회원가입을 받지 않으며 차량번호·차대번호(VIN) 입력란을 제공하지 않습니다.

차량번호와 VIN

개별 차량의 리콜 대상 여부는 자동차리콜센터로 이동해 확인합니다. 차량번호와 VIN을 이 사이트의 URL, 로그, Analytics, LocalStorage에 저장하지 않는 것을 원칙으로 합니다.

계산 입력값

주행거리, 연료가격, 최초등록월은 브라우저 화면에서 계산에만 사용합니다. 현재 페이지는 서버로 전송하거나 저장하지 않습니다.

향후 분석 도구

운영 도메인에서 방문 분석 또는 광고 서비스를 도입할 경우 사용 서비스, 수집 항목, 보관 기간, 거부 방법을 이 페이지에 먼저 공개합니다.

외부 사이트

현대자동차, 국가법령정보센터, 오피넷, 자동차리콜센터로 이동한 뒤의 개인정보 처리는 각 서비스의 정책을 따릅니다.
