미디어·저작권 정책

차량 식별에 필요한 사진만 사용하고 저작자·출처·라이선스 조건을 이미지 가까이에 표시합니다.

사용 기준

검색엔진 이미지 결과를 무단 복제하지 않습니다. Wikimedia Commons 등에서 상업적 이용과 재배포 조건을 확인할 수 있는 이미지를 우선 사용합니다.

현재 차량 사진

그랜저 GN7, 쏘렌토 MQ4, K8, 아이오닉 5, G80 등은 Wikimedia Commons의 라이선스 확인 사진을 사용하며 각 화면의 사진 가까이에 저작자와 CC 라이선스를 표시합니다. EV6·아반떼 등도 동일 기준을 적용합니다.

운영 이미지 최적화

운영 환경에서는 라이선스·저작자 정보를 유지한 채 필요한 해상도로 자체 최적화한 WebP/AVIF 파생본과 srcset을 사용할 수 있습니다. 원본 저작자·라이선스 표시는 삭제하지 않습니다.

오류 신고

차종이 잘못 연결됐거나 저작자·라이선스 표시가 정확하지 않은 경우 문의 페이지로 알려주세요.
