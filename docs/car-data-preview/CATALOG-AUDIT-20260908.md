## 정렬

공개 프리뷰에서 기존 두 정렬은 서로 다른 목록을 반환했다. 다만 첫 세 항목이 모두 니로·레이·모닝이라 첫 화면만 보면 변화가 드러나지 않았다. 기존 `제조사·차량명순`은 두 개가 아닌 하나의 정렬이었다.

- 사진 있는 차량 먼저: 사진 보유 여부 → 제조사 → 차량명.
- 제조사순: 제조사 → 차량명. 기존 `sort=name` 링크 의미 유지.
- 차량명순: 제조사와 관계없이 차량명 → 제조사. `sort=model` 추가.
- 동률은 family_id로 안정적으로 정렬한다. 정렬 변경 시 첫 페이지로 이동한다.
- 검색·제조사 필터·페이지 이동·URL 복원·초기화와 함께 검증했다. 390px 및 1280px에서 세 정렬의 첫 두 페이지를 실제 전체 데이터와 대조했다.
- 배포 후 이전 스크립트 캐시가 남지 않도록 내용 해시를 URL에 붙인다.
