차량 비교

같은 조건으로 비교

전체 공식 신고 사양에서 두 차량을 고르고 같은 주행거리와 에너지 가격으로 비교합니다. 계산 조건이 부족한 항목은 임의의 0원 대신 제외 사유를 표시합니다.

비교 조건

리콜

리콜 건수는 우열 점수가 아닙니다.

리콜은 생산기간·세부 사양에 따라 대상이 달라 비교표의 안전점수로 쓰지 않습니다. 각 모델 공지는 리콜 페이지에서 별도로 확인합니다.

모델 리콜 확인계산 기준
비교 결과는 선택 신고 사양과 입력 가정에 따른 계산값이며 구매가격·보험·정비·감가·취득세는 포함하지 않습니다.
