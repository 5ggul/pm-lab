비교 조건

자동차세는 차령 경감 전 신차 기준 연간 정상세액입니다. 보험료·정비비·구매가격·취득세는 합계에 포함하지 않습니다. 전기차 충전단가는 입력 전까지 에너지비와 합계를 계산하지 않습니다.

리콜

리콜 건수는 우열 점수가 아닙니다.

리콜은 생산기간·세부 사양에 따라 대상이 달라 비교표의 안전점수로 쓰지 않습니다. 각 모델 공지는 리콜 페이지에서 별도로 확인합니다.
