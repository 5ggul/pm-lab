자주 묻는 질문

하이브리드는 세율이 다른가요?

일반 비영업용 승용 하이브리드는 엔진 배기량에 따른 표준세율로 계산합니다. 연비가 높다고 자동차세가 직접 줄어드는 것은 아닙니다.

배기량 구간마다 나눠서 계산하나요?

아닙니다. 해당 구간의 세율을 전체 배기량에 곱합니다. 1,598cc는 cc당 140원, 1,601cc는 cc당 200원을 적용합니다.

몇 년 된 차부터 줄어드나요?

배기량으로 과세하는 비영업용 승용차는 법정 차령 3년부터 매년 5%씩, 최대 50%까지 경감합니다. 상·하반기의 차령이 다를 수 있어 월을 입력받습니다.

전기차도 오래되면 줄어드나요?

이 계산기에서 전기 승용차는 본세 10만 원과 지방교육세 3만 원을 합산합니다. 배기량 과세 차량의 차령 경감은 적용하지 않습니다.

실제 고지서와 왜 다른가요?

연납 할인, 개별 감면, 지자체 조례, 연중 등록·말소에 따른 일할계산을 반영하지 않은 연간 추정치입니다. 고지액은 위택스나 관할 지자체에서 확인하세요.
