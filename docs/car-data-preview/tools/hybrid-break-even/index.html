차량가격 차이는 무엇을 입력하나요?

비교할 두 사양의 실제 구매 견적 차이를 입력하세요. 할인과 선택품목을 같은 기준으로 맞춰야 합니다. 가격 차이를 입력하기 전에는 회수기간을 계산하지 않습니다.

회수기간은 어떻게 계산하나요?

하이브리드 추가 구매비 ÷ 연간 자동차세·연료비 절감액입니다. 예를 들어 300만원을 더 지불하고 매년 100만원을 아끼면 단순 회수기간은 3년입니다.

차령에 따라 세금이 줄어드는 것도 포함되나요?

아니요. 선택 사양의 신차 세금과 입력 유가·주행거리를 매년 일정하게 둔 단순 계산입니다. 장기 실제 비용 예측이나 중고차 잔존가치는 포함하지 않습니다.

절감액이 0원이거나 음수면 어떻게 되나요?

현재 조건으로 추가 구매비를 회수할 수 없다고 표시합니다. 추가 구매비 자체가 0원 이하이면 회수할 추가 비용이 없습니다.

보험·정비·배터리 교체비도 들어가나요?

들어가지 않습니다. 구매가격 차이와 자동차세·연료비만 다룹니다. 향후 유가, 세율, 운행량 변화도 가정하지 않습니다.
