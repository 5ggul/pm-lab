이용안내

내차데이터는 자동차 공식 데이터와 법정 표준세율을 정리하고 같은 가정의 1년 비용 계산을 돕는 비공식 서비스입니다.

계산 결과

자동차세와 에너지비는 선택한 차량 사양과 입력 가정에 따른 추정치입니다. 실제 고지액, 실연비, 주유비·충전비를 보장하지 않습니다.

포함하지 않는 항목

구매가격, 보험료, 정비비, 감가상각, 취득세는 Phase 1의 연간 합계에 포함하지 않습니다. 각 결과 화면에도 이 범위를 표시합니다.

리콜

모델 리콜 공지는 참고 정보이며 개별 차량의 실제 대상 여부는 자동차리콜센터에서 자동차등록번호 또는 VIN으로 확인해야 합니다.

공식 원문 우선

차량 사양, 세법, 유가, 리콜 정보는 변경될 수 있습니다. 제조사와 관계 기관의 최신 원문이 이 사이트의 표시보다 우선합니다.

콘텐츠와 이미지

차량 이미지는 사용 조건을 확인할 수 있는 자료만 사용하며 저작자·출처·라이선스를 이미지 가까이에 표시합니다.
