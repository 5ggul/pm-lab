자동차 비용 계산 결과 확인 순서

거리·사양·단가·포함 항목을 확인해 잘못된 비교를 줄입니다.

첫째, 실제 계약할 사양인지 확인합니다

같은 차명에도 엔진, 연료, 연식, 2WD·AWD, 휠과 인승이 여러 개입니다. 차량 상세에서 선택한 사양명이 견적서와 맞는지 확인하세요. 연비 순위의 최고 수치를 다른 휠이나 구동 사양에 그대로 적용하면 계산 결과가 실제 후보와 달라집니다.

둘째, 주행거리와 단가 날짜를 봅니다

기본 20,000km는 비교용 입력값입니다. 자신의 최근 1년 거리로 바꾸고, 유가는 화면에 표시된 오피넷 수집일을 확인하세요. 자주 가는 주유소 가격을 안다면 직접 입력할 수 있습니다. 전기차는 충전 사업자와 회원 조건에 따라 가격 차이가 커서 기본 단가를 제공하지 않습니다.

셋째, 효율 단위를 구분합니다

내연기관과 일반 하이브리드는 km/L, 전기차는 km/kWh를 사용합니다. 숫자 크기만 직접 비교하지 마세요. 비용은 내연기관의 경우 거리 ÷ 연비 × 원/L, 전기차는 거리 ÷ 전비 × 원/kWh로 계산한 뒤 같은 기간의 원 단위 결과로 비교합니다.

넷째, 포함되지 않은 비용을 확인합니다

종합 계산 결과는 자동차세와 연료비 또는 충전비의 합계입니다. 구매가격, 취득세, 보험, 정비, 소모품, 통행료, 주차료와 감가상각은 포함하지 않습니다. 자동차세도 연납 할인, 개별 감면, 일할계산을 제외한 정상세액 기준이므로 실제 고지액은 위택스와 지자체 안내를 확인하세요.
