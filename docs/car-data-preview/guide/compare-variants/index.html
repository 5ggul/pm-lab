차량비교계산 도구가이드

두 차량을 비교하기 전에 맞출 네 가지

연식·동력·구동·휠을 확인한 뒤 같은 주행 조건을 입력합니다.

1. 연식과 세대

차종명이 같아도 세대가 바뀌면 제원과 연비가 달라집니다. 순위의 과거 사양을 최신 모델의 수치로 바꾸어 읽지 마세요. ‘이 사양 보기’ 링크는 표시된 등록 자료를 확인하는 데 사용합니다.

2. 엔진과 연료

가솔린, 경유, LPG, 하이브리드, 전기차는 연료와 효율 단위가 다릅니다. km/L와 km/kWh 숫자의 크기를 직접 비교하지 마세요. 비용으로 비교하려면 각 연료의 가격이나 충전단가가 필요합니다.

3. 구동 방식과 휠

2WD·AWD와 휠 크기를 확인하세요. 두 차량에 완전히 같은 구성이 없다면 차이를 지우지 말고 그대로 기록해야 합니다. 이 사이트의 정적 비교 페이지도 실제 선택된 사양을 먼저 표시합니다.

4. 주행거리와 가격 기준

두 차량의 연간 주행거리를 같게 두고 동일 기준일의 유가를 사용합니다. 전기차는 실제 사용할 충전단가를 입력하세요. 결과에 자동차세가 포함됐는지, 구매비·보험·정비가 빠졌는지도 함께 읽어야 비교 범위가 분명해집니다.
