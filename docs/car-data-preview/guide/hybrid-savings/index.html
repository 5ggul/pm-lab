하이브리드 연료비 절감액과 구매비 구분하기

연료비 차이만으로 구매가격 회수 기간을 판단하지 않습니다.

같은 거리와 같은 유가로 계산

연비 12km/L와 18km/L인 두 차를 연 20,000km, 휘발유 1,800원/L로 비교하면 연료비는 각각 300만 원과 200만 원입니다. 차이는 연 100만 원입니다. 이 수치는 계산 예시이며 특정 모델의 결과가 아닙니다.

거리가 절반이면 연료비 차이도 절반

다른 조건이 같고 연간 거리가 10,000km이면 차이는 50만 원입니다. 연비가 좋아도 운행이 적으면 절감액은 작아집니다. 비교 페이지에서 기본 거리만 읽지 말고 자신의 연간 거리로 바꿔 보세요.

구매가격 차이는 별도 입력 정보

연료비 절감액은 구매비를 회수하는 기간이 아닙니다. 실제 차량 견적의 차이, 자동차세, 보험, 정비와 처분 가격 등이 추가로 필요합니다. 이 사이트의 사양 비교는 구매가격 차이를 포함하지 않으므로 ‘몇 년이면 본전’이라고 표시하지 않습니다.

같은 이름의 트림도 조건 확인

가솔린과 하이브리드의 기본 휠이나 구동 조건이 다를 수 있습니다. 비교 페이지에서 선택 사양과 차이를 확인하고, 실제 계약할 두 견적의 조건을 따로 맞추세요. 연료비가 낮다는 결과와 최종 구매 결정은 구분하는 것이 좋습니다.
