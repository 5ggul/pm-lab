급속·완속을 섞어 쓰는 충전비 계산

충전 횟수 대신 결제 전력량으로 평균 단가를 구합니다.

먼저 전비의 단위를 확인

이 계산기는 km/kWh를 사용합니다. 전비 5km/kWh라면 1,000km를 달리는 데 계산상 200kWh가 필요합니다. 충전단가가 350원/kWh이면 비용은 70,000원입니다. 특정 차종이나 사업자의 현행 가격을 뜻하는 예시는 아닙니다.

혼합 단가는 전력량으로 가중 평균

300원/kWh로 70kWh, 450원/kWh로 30kWh를 충전했다면 총 100kWh에 34,500원을 쓴 셈입니다. 평균 단가는 345원/kWh입니다. 충전 횟수를 반반으로 세어 375원을 적용하면 실제 사용 비중과 달라집니다.

계기판 값과 청구 전력량의 범위

공식 전비, 차량 화면의 주행 전비, 충전기 결제 전력량은 같은 측정값이라고 단정할 수 없습니다. 이 도구는 임의의 충전 손실률을 추가하지 않습니다. 내 지출을 확인할 때는 같은 기간의 주행거리와 실제 충전 영수증을 함께 보세요.

전력 요금 밖의 비용

주차료, 충전 완료 후 점유 요금, 정기 구독료는 별도입니다. 계산 결과를 전체 충전 관련 지출로 해석하지 마세요. 충전단가는 기본값을 두지 않으므로 이용할 충전기의 회원 요금과 결제 조건을 직접 확인해 입력하세요.
