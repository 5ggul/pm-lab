- 오피넷 수집 실패 시 마지막 정상 수집일 또는 직접 입력 상태를 표시한다.
- 차량 상세와 순위의 숫자는 JavaScript 없이도 읽을 수 있어야 한다.
- 공개 문구에 내부 작업 용어와 `준비 중`을 노출하지 않는다.
- 사진은 차종·세대 연결과 상업 이용 조건을 확인한 것만 사용한다.
- `noindex,nofollow,noarchive`는 최종 도메인 전환 전까지 유지한다.
