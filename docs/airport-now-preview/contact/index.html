데이터가 이상하거나 설명이 틀렸다면 알려주세요

공항나우는 운항정보와 항공기상의 기준시각·출처·정규화 과정에서 생길 수 있는 오류를 빠르게 확인할 수 있도록 제보를 받습니다.

GitHub에서 오류 제보하기 ›데이터 출처 확인

오류 제보에 무엇을 적으면 되나요?

가능하면 문제가 보인 페이지 주소, 공항 또는 항공편 번호, 화면에서 본 기준시각과 잘못됐다고 생각한 항목을 적어주세요. 재현 가능한 정보가 많을수록 원본 API와 가공 결과를 빠르게 비교할 수 있습니다.

  • 페이지 URL
  • 공항명 또는 항공편 번호
  • 확인한 날짜·시각
  • 잘못됐다고 생각한 값 또는 문장
  • 가능하면 화면 캡처

어떤 문의를 받을 수 있나요?

데이터 오류, 출처 정정, 용어·방법론 설명의 오류, 접근성·모바일 화면 문제, 기능 제안과 데이터 활용 제안을 제보할 수 있습니다.

항공편 변경·환불·탑승 문의는 처리하지 않습니다

공항나우는 항공사나 공항 공식 고객센터가 아닙니다. 결항·재예약·환불·체크인 마감·수하물·게이트 변경처럼 승객별 처리가 필요한 문의는 해당 항공사와 공항 공식 채널에 문의해야 합니다.
