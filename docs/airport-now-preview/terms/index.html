이용약관

공항나우가 제공하는 데이터·설명·도구의 성격과 이용자가 공식 안내를 우선해야 하는 범위를 정합니다.

1. 서비스의 성격

공항나우는 공항공사와 기상청 등 공식 제공기관의 데이터를 정리하고, 공동운항 중복·시간 차이·항공기상 용어를 이용자가 이해하기 쉽게 가공해 제공하는 독립 정보 서비스입니다. 공항나우는 항공사·공항·정부기관의 공식 서비스가 아닙니다.

2. 공식 안내 우선

탑승수속 마감, 탑승구 변경, 결항, 회항, 재예약, 환불, 수하물, 출입국 절차와 같이 즉시 행동이나 승객별 처리가 필요한 사항은 항공사와 공항의 최신 공식 안내를 우선해야 합니다.

3. 데이터의 최신성과 정확성

공항나우는 기준시각과 출처를 표시하고 오래된 관측을 현재값에서 제외하는 등 품질 기준을 적용합니다. 다만 원 제공기관의 전송 지연·누락·정정, 네트워크 장애, 시스템 갱신 차이로 화면과 실제 현장 상황 사이에 차이가 생길 수 있습니다.

4. 자체 계산과 도구

지연시간 계산, 마중시간 계산, 향후 제공되는 지연률·최근 평균 비교는 사용자의 이해를 돕는 보조 정보입니다. 마중시간 계산기는 사용자가 직접 선택한 여유시간을 단순 합산하며 실제 입국·수하물 소요시간을 예측하지 않습니다.

5. 항공기상 정보

METAR, CAVOK, 풍속·돌풍·시정 등은 항공기상 이해를 위한 정보입니다. 공항나우는 기상자료만으로 특정 항공편의 운항 가능 여부나 결항을 확정하지 않습니다.

6. 외부 링크

공항나우는 확인과 출처 제공을 위해 공항, 항공사, 공공데이터포털, 기상청, GitHub 등의 외부 사이트로 연결할 수 있습니다. 외부 사이트의 콘텐츠와 이용조건은 해당 서비스가 책임집니다.

7. 서비스 변경과 중단

공식 API 구조 변경, 데이터 제공 중단, 시스템 점검 또는 품질 문제로 일부 기능이나 데이터가 일시적으로 제공되지 않을 수 있습니다. 확인되지 않은 값을 임의로 채우기보다 해당 모듈을 숨기거나 제공 범위를 축소할 수 있습니다.

8. 약관 변경

서비스 범위나 데이터 이용방식이 달라질 경우 이 약관을 갱신할 수 있습니다.
