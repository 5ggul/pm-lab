인천공항 마중시간 계산기

예상 도착시각에 내가 잡고 싶은 입국·수하물 여유시간을 더해 만날 목표시간을 계산합니다.

이 계산기는 ‘평균 입국시간’을 예측하지 않습니다

입국심사와 수하물 수취시간은 항공편, 도착시간대, 승객 수, 수하물 여부 등에 따라 달라집니다. 그래서 공항나우가 임의의 평균시간을 자동 추천하지 않고 사용자가 직접 여유시간을 선택하도록 했습니다.

마중 전 마지막으로 확인할 것

항공편이 ‘착륙’인지 ‘도착’인지, 터미널이 T1인지 T2인지, 예상 도착시각이 다시 바뀌지 않았는지 확인하세요. 실제 입국장 도착은 항공기 도착보다 늦습니다.
