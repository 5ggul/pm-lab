예시 문장을 해석해 보세요.

여행자는 무엇을 먼저 보면 되나요?

관측시각이 최신인지 확인한 뒤 바람, 돌풍, 시정을 보세요. CAVOK가 있으면 항공기상상 양호한 조건을 빠르게 파악하는 데 도움이 됩니다. 다만 METAR만으로 특정 항공편의 결항·지연을 단정할 수는 없습니다.

이 해석기의 범위

일반적인 METAR 토큰 가운데 여행자에게 자주 필요한 항목만 해석합니다. 전문 운항 판단이나 조종·운항 업무용 도구가 아닙니다.
