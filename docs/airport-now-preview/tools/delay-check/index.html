항공편 지연시간 계산기

예정시간과 현재 예상·변경시간을 비교해 차이를 분 단위로 계산합니다.

지연시간은 어떻게 해석하나요?

이 계산기는 두 시각의 단순 차이만 계산합니다. 실제 항공편의 공식 상태는 항공사와 공항이 제공하는 지연·결항 표시가 우선합니다. 예상시간은 운항상황에 따라 다시 바뀔 수 있습니다.

지연됐어도 공항에 늦게 가면 안 되는 이유

체크인과 수하물 위탁 마감은 항공편 지연과 별도로 적용될 수 있습니다. 항공사가 별도 안내하지 않았다면 기존 수속 마감 기준을 따르는 것이 안전합니다.
