공항나우는 공식 데이터를 어디서 가져오나요?

운항정보와 항공기상을 서로 다른 제공기관에서 받아 한 화면에 정리하되, 원본 상태와 기준시각을 섞지 않는 것을 원칙으로 합니다.

인천국제공항공사

인천공항 여객편 운항정보를 사용합니다. 도착편에서는 편명, 예정·예상시간, 출발지, 터미널, 게이트, 수하물과 상태를 확인합니다.

공동운항은 왜 중복 제거하나요?

같은 항공기가 여러 항공사 편명으로 표시될 수 있기 때문입니다. 공항나우는 실제 운항편을 한 건으로 두고 다른 판매 편명은 검색용 별칭으로 분리해 운항편 수와 지연률이 부풀지 않게 설계합니다.

오래된 날씨는 왜 안 보여주나요?

API 요청이 성공했다는 사실과 관측이 최신이라는 사실은 다릅니다. 관측시각이 오래된 METAR는 과거 기록으로는 의미가 있어도 현재 공항 상황으로 보여주면 오해를 만들 수 있어 현재 화면에서 제외합니다.

날씨와 지연을 왜 바로 연결하지 않나요?

강풍·저시정과 지연이 같은 시간에 나타나도 공식 원인정보가 없다면 인과관계를 확인한 것이 아닙니다. 공항나우는 기상과 운항상태를 나란히 보여주되 원인이라고 단정하지 않습니다.

향후 자체 통계는 어떻게 만드나요?

개별 운항편의 의미 있는 상태 변화만 이력으로 남기고, 공항 시간대·노선·편명별 일 단위 집계를 별도로 보관합니다. 충분한 표본이 쌓이면 ‘지금 vs 최근 같은 요일·시간대’ 비교를 제공합니다.
