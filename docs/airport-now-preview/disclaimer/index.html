면책 및 데이터 정확성 고지

공항나우는 공식 데이터를 이해하기 쉽게 정리하지만, 현장 운영과 승객별 최종 안내를 대신하지 않습니다.

운항정보에는 갱신 차이가 생길 수 있습니다

공항공사·항공사·데이터 제공시스템 사이의 갱신시각 차이, 네트워크 전송 지연, 원 데이터 정정으로 인해 같은 항공편이 잠시 다른 시간이나 상태로 보일 수 있습니다. 공항나우는 가능한 경우 데이터 기준시각을 함께 표시합니다.

항공기상은 관측시각을 확인합니다

METAR 요청이 정상 처리됐더라도 관측시각이 오래됐다면 현재 공항 날씨로 사용하지 않습니다. 데이터 미표시는 공항이 운영하지 않는다는 뜻이 아닙니다.

자체 계산은 공식 발표가 아닙니다

지연시간, 향후 제공될 공항 지연률·최근 평균 비교는 공식 원인을 발표하는 값이 아니라 원본 운항정보를 정해진 방법으로 가공한 보조 지표입니다. 계산 방식은 방법론 페이지에 공개합니다.

기상과 지연의 인과관계를 임의로 만들지 않습니다

강풍·저시정 등 기상상태와 항공편 지연이 같은 시간에 나타나더라도 공식 원인자료가 없으면 ‘날씨 때문에 지연됐다’고 단정하지 않습니다.

최종 행동은 공식 안내가 우선합니다

탑승수속 마감, 게이트 변경, 결항, 회항, 재예약, 환불, 수하물, 출입국 절차는 해당 항공사와 공항의 최신 공식 안내를 확인하세요.

오류를 발견했다면

페이지 주소, 공항·항공편, 확인시각과 문제가 된 값을 함께 오류제보 페이지에서 알려주면 원본과 가공 결과를 비교할 수 있습니다.
