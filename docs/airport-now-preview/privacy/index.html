개인정보처리방침

현재 공항나우 화면에서 어떤 사용자 정보를 직접 수집하는지와 수집하지 않는 범위를 설명합니다.

1. 현재 직접 수집하는 개인정보

현재 공개된 공항나우 화면은 회원가입, 로그인, 이름·전화번호·이메일 입력을 요구하지 않습니다. 별도 문의 폼도 운영하지 않으며 오류 제보는 외부 GitHub 페이지로 이동해 진행합니다.

2. 검색창 입력

공항·편명 검색은 브라우저에서 정적 검색 목록을 불러온 뒤 사용자가 입력한 문자열과 일치하는 항목을 화면에서 찾는 방식입니다. 현재 검색창의 검색어를 공항나우가 별도 데이터베이스에 저장하도록 구현하지 않았습니다.

3. 호스팅 과정의 기술 정보

사이트를 제공하는 호스팅 사업자와 네트워크 사업자는 서비스 제공·보안·장애 대응을 위해 접속 IP, 브라우저 정보, 요청 시각과 같은 기술 정보를 각자의 정책에 따라 처리할 수 있습니다. 이 정보의 처리는 해당 사업자의 정책을 따릅니다.

4. 외부 링크

공항·항공사·공공데이터포털·GitHub 등 외부 사이트로 이동한 뒤의 개인정보 처리는 해당 서비스의 개인정보처리방침이 적용됩니다.

5. 광고·분석 도구

현재 공항나우 화면에는 광고 네트워크나 사용자 행동 분석 도구를 활성화하지 않았습니다. 향후 광고, 분석, 문의 폼, 알림 등 개인정보 처리 범위가 달라지는 기능을 도입할 경우 실제 적용 전에 이 방침을 갱신합니다.

6. 방침 변경

수집 항목, 이용 목적, 보유기간, 제3자 제공 또는 처리위탁 내용이 생기거나 변경되면 적용 전후의 내용을 확인할 수 있도록 이 페이지를 수정합니다.
