METAR 뜻: 공항 관측시각과 읽는 순서

METAR는 공항의 정기 항공기상 관측 보고입니다. 앞으로의 날씨를 예보하는 TAF와 구분해서 읽어야 합니다.

내용 확인일: 2026-09-07 · 실제 운항 판단은 항공사·공항 공식 안내가 우선합니다.

어떤 뜻인가요?

공항 식별 코드와 관측시각을 먼저 확인한 뒤 바람, 시정, 구름, 기온, 기압 항목을 읽습니다. 같은 공항 이름이 보여도 관측시각이 오래됐다면 현재 운항 상황을 설명하는 근거로 사용할 수 없습니다.

조회 화면에서는 어떻게 읽나요?

공항나우는 최근 관측이 확인되는 경우에만 현재 기상으로 표시합니다. 조회 요청이 성공한 시각과 실제 기상이 관측된 시각은 다릅니다. 요청이 방금 성공했어도 원본 관측이 오래되면 최신 날씨가 아닙니다.

다음으로 무엇을 확인하나요?

METAR는 공항 기상을 이해하는 자료이며 특정 항공편의 탑승 가능 여부를 결정하는 안내가 아닙니다. 지연이나 결항을 확인하려면 같은 공항의 실제 항공편 상태와 항공사 공지를 함께 보세요.
