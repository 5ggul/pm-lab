공동운항 뜻: 예약 편명과 실제 운항편 찾기

공동운항은 실제로 운항하는 한 항공편을 다른 항공사도 자기 편명으로 판매하는 방식입니다. 여러 편명이 표시돼도 같은 비행기일 수 있습니다.

내용 확인일: 2026-09-07 · 실제 운항 판단은 항공사·공항 공식 안내가 우선합니다.

어떤 뜻인가요?

예약 내역에서 판매 항공사와 실제 운항사를 구분하세요. 조회가 안 되면 실제 운항편 번호와 도착 날짜를 함께 확인하는 것이 좋습니다. 수하물이나 수속 안내는 해당 예약의 적용 규정을 따로 확인해야 합니다.

조회 화면에서는 어떻게 읽나요?

같은 시각에 여러 편명이 보인다고 각각 다른 비행기로 세면 공항 전체 편수가 부풀 수 있습니다. 공항나우는 실제 운항편을 기준으로 묶고 판매 편명은 검색용 별칭으로 연결합니다.

다음으로 무엇을 확인하나요?

같은 시간과 노선이라는 이유만으로 공동운항으로 묶지는 않습니다. 공식 데이터의 실제 운항편 연결 정보가 필요합니다. 결과를 비교할 때 편명뿐 아니라 날짜·출발지·도착지까지 맞춰보세요.
