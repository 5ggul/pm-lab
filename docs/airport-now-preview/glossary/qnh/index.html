QNH 뜻: METAR 기압값을 보는 방법

QNH는 고도계 설정에 사용하는 기압값입니다. 공항나우의 QNH 표시는 hPa 단위이며, 숫자 하나로 결항 가능성을 판단하는 지표가 아닙니다.

내용 확인일: 2026-09-07 · 실제 운항 판단은 항공사·공항 공식 안내가 우선합니다.

어떤 뜻인가요?

METAR에서 Q로 시작하는 네 자리 숫자는 QNH를 hPa로 나타냅니다. 예를 들어 Q1013은 1013 hPa를 뜻합니다. 다른 보고 형식의 기압 표기와 단위를 혼동하지 않도록 원문과 단위를 함께 확인하세요.

조회 화면에서는 어떻게 읽나요?

여행자는 QNH만 낮아졌다고 결항을 예상하기보다 관측시각과 바람·시정, 실제 항공편 상태를 우선 확인하는 편이 낫습니다. 공항나우는 기압 수치와 항공편 지연 사이의 인과관계를 자동으로 단정하지 않습니다.

다음으로 무엇을 확인하나요?

값이 비어 있다면 이전 기압을 임의로 현재값처럼 채우지 않습니다. 기압 관측이 없다는 사실과 항공편이 운항하지 않는다는 사실은 서로 다르므로 공식 운항 조회로 이어서 확인하세요.
