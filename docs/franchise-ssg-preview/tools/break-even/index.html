손익분기 회수기간 계산기

월 매출에서 원재료·인건비·월세·수수료·로열티·기타비를 뺀 단순 월 잉여로 초기투자금을 나눕니다.

단순 회수기간 계산 중

계산식

단순 회수개월 = 초기투자금 ÷ 월 단순잉여 (월 단순잉여 ≤ 0이면 계산하지 않음)

계산 예

커피 예시

초기투자 1억4,000만원, 월 단순잉여 500만원 → 28.0개월

치킨 예시

초기투자 1억8,000만원, 월 단순잉여 600만원 → 30.0개월

기본 계산에서 제외하는 항목

  • 세금
  • 감가상각
  • 대출이자
  • 점주 인건비 처리
  • 계절성
  • 폐업비용

자주 묻는 질문

28개월이면 실제로 28개월 뒤 회수되나요?

아닙니다. 같은 가정이 유지된다는 단순 산술입니다.

잉여가 음수면요?

회수기간을 표시하지 않습니다.

세금은 포함되나요?

기본 계산에서는 제외하고 별도 검토해야 합니다.

매출은 무엇을 넣나요?

사용자가 가정한 월 매출을 넣습니다.

다음에 같이 확인할 도구

월손익월 매출과 변동비·고정비를 입력해 단순 영업잔액을 확인월고정비월세·관리비·고정 인건비·원리금 등 매달 고정되는 금액을 합산

한 번의 결과보다 조건을 바꿔 비교하세요

회수기간은 월 매출과 원가율·인건비·임차비 가정에 크게 달라집니다. 하나의 결과를 확정값으로 보지 말고 보수적·기준·낙관 조건으로 입력값을 바꿔 결과 범위를 비교하세요. 특히 초기투자금에 임대보증금·권리금·추가공사와 오픈 초기 운전자금을 포함했는지 먼저 확인해야 합니다.
