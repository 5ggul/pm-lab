프랜차이즈 창업비용 계산기

브랜드 공개비용과 임대보증금·권리금·별도공사·초도물품·운전자금을 분리해서 더합니다.

계산 결과 15,000만원

계산식

총 초기 필요자금 = 브랜드 공개비용 + 임대보증금 + 권리금 + 추가공사 + 추가설비 + 초도물품 + 운전자금 + 기타 준비비

계산 예

커피 예시

공개비용 8,000 + 임대보증금 3,000 + 권리금 1,500 + 운전자금 1,500 = 1억4,000만원

치킨 예시

공개비용 1억1,000 + 임대보증금 4,000 + 추가설비 1,000 + 운전자금 2,000 = 1억8,000만원

자주 묻는 질문

공개 창업비용과 총 준비자금은 같은가요?

아닙니다. 점포별 비용을 따로 더해야 합니다.

권리금이 없으면 0으로 넣어도 되나요?

실제 무권리 점포라는 조건일 때 가능합니다.

월세는 초기투자에 넣나요?

보통 월 운영비로 별도 표시합니다.

결과가 실제 견적인가요?

아닙니다. 입력값을 더한 가정 기반 계산입니다.
