정보공개서 공개합계와 점포 임대·권리금·추가공사 비용을 섞지 않고 따로 더합니다.

공개합계는 실제 총투자금이 아닙니다

점포 조건에 따라 임대보증금, 권리금, 철거, 증설, 외부공사와 운전자금이 추가될 수 있습니다.

계산 공식과 빠지는 항목
총 초기 필요자금 = 브랜드 공개비용 + 임대보증금 + 권리금 + 추가공사 + 초도물품 + 운전자금. 세금, 대출이자, 중개보수, 공사기간 임차료, 예비비는 별도일 수 있습니다.

왜 공개 창업비용과 실제 준비자금을 나눠야 하나요?

정보공개서의 창업비용은 가맹본부 관련 표준 비용을 비교하기에는 유용하지만, 특정 상가의 임대보증금과 권리금, 철거·전기증설·냉난방·외부공사, 오픈 초기 운영현금을 모두 포함한다는 뜻은 아닙니다. 그래서 계산기는 공식값을 자동 입력하되 점포별 비용은 사용자가 따로 넣도록 설계했습니다.

결과는 실제 견적인가요?

아닙니다. 입력값을 합한 단순 시뮬레이션입니다. 계약 전에는 최신 정보공개서, 가맹본부 견적, 임대차계약과 공사업체 견적을 함께 확인해야 합니다.
