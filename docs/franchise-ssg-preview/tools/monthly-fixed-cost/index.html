월고정비

월세·관리비·인건비·대출 원리금·보험·통신·POS·기타 고정비를 합산해 매달 필요한 현금 규모를 확인합니다.

입력한 항목만 합산합니다.

월 고정비 합계입력 대기
선택 기간 예비자금입력 대기

원재료·카드수수료·배달수수료처럼 매출에 따라 달라지는 비용은 이 계산에 포함하지 않습니다.

계산식

월 고정비 = 월세 + 관리비 + 고정 인건비 + 대출 원리금 + 보험 + 통신·POS + 기타 고정비

계산 예

소형점

월세 250 + 관리 40 + 인건비 700 + 기타 160 = 1,150만원

중형점

월세 450 + 관리 90 + 인건비 1,400 + 기타 260 = 2,200만원

기본 계산에서 제외하는 항목

  • 카드수수료
  • 배달수수료
  • 세금

자주 묻는 질문

원재료비는 고정비인가요?

판매량에 따라 달라지므로 보통 변동비로 분리합니다.

점주 급여도 넣나요?

실제 의사결정에서는 점주 노동비를 별도 가정하는 편이 좋습니다.

대출 원금도 넣나요?

현금흐름 관점에서는 월 원리금 상환액을 입력할 수 있습니다.

몇 개월 예비자금을 잡나요?

사이트가 정답을 제시하지 않고 사용자가 기간을 선택하도록 합니다.
