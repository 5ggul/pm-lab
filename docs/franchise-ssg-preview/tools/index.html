손익분기 회수기간 계산기

월 매출에서 원재료·인건비·월세·수수료·로열티·기타비를 뺀 단순 월 잉여로 초기투자금을 나눕니다.

월 고정비 계산기

월세·관리비·인건비·대출 원리금·보험·통신·POS·기타 고정비를 합산해 매달 필요한 현금 규모를 확인합니다.

반경 점포 수·상권 밀도 계산기

선택 업종의 지역 업소 수와 면적, 또는 중심점 반경 300m·500m·1km 안의 점포 수를 계산합니다. 공급량만 보여주며 매출을 예측하지 않습니다.

정보공개서 비용 항목 해독기

정보공개서의 가맹금·교육비·보증금·기타비·인테리어 항목을 입력하면 성격과 점포별 추가확인 항목을 나눠 보여줍니다.

가맹점 개·폐업률 계산기

기준 점포 수와 신규·종료·해지 건수를 입력해 신규율과 종료·해지 비율을 같은 분모로 계산합니다.

업종 중앙값 대비 창업비용 위치 계산기

브랜드 공개비용을 같은 업종의 검수된 브랜드 비용 분포와 비교해 중앙값보다 얼마나 높거나 낮은지만 보여줍니다.

조건으로 프랜차이즈 브랜드 찾기
