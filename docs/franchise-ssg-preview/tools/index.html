프랜차이즈 창업 계산기·분석 도구

현재 데이터·입력 의미를 검증한 8개 도구만 모았습니다. 공식 공개값, 사용자가 넣는 가정, 공개값에서 계산한 파생 통계를 서로 구분합니다.

무엇을 확인하려는지부터 고르세요

도구확인하는 것값의 기준
창업비용 계산기공개비용에 보증금·권리금·별도 공사를 더해 준비자금 범위를 확인공식 공개값 + 사용자 입력
정보공개서 비용 항목 계산기가맹비·교육비·보증금·기타비·인테리어 항목을 분리해 합계를 확인사용자 입력
월 고정비 계산기월세·관리비·고정 인건비·원리금 등 매달 고정되는 금액을 합산사용자 입력
월 손익 계산기월 매출과 변동비·고정비를 입력해 단순 영업잔액을 확인사용자 입력
손익분기 계산기투자금과 월 잔액을 기준으로 단순 회수기간을 계산사용자 입력
브랜드 조건 찾기업종·공개비용·가맹점 수·점포 증감 조건으로 브랜드를 좁혀 보기공식 매칭 공개값
업종 중앙값 비교선택 브랜드 공개비용을 같은 업종의 공식 매칭 중앙값과 비교공식 매칭값의 파생 통계
가맹점 개·폐업률 계산기기준 점포 수와 신규·종료·해지 건수를 같은 분모로 계산사용자 입력

공식값과 입력값을 섞지 않습니다

공식 매칭 공개값
공정거래위원회 공개자료와 안전 매칭한 브랜드 값입니다. 누락값은 0으로 바꾸지 않습니다.
사용자 입력
월세·인건비·매출·권리금처럼 사용자가 직접 넣은 가정입니다. 사이트가 평균값을 임의로 채우지 않습니다.
파생 통계
공식 매칭값 중 실제 값이 확인된 표본만 사용해 중앙값·비율 등을 계산한 값입니다.

초기 투자·준비자금

창업비용 계산기공개비용에 보증금·권리금·별도 공사를 더해 준비자금 범위를 확인정보공개서 비용 항목 계산기가맹비·교육비·보증금·기타비·인테리어 항목을 분리해 합계를 확인월 고정비 계산기월세·관리비·고정 인건비·원리금 등 매달 고정되는 금액을 합산

운영·회수

월 손익 계산기월 매출과 변동비·고정비를 입력해 단순 영업잔액을 확인손익분기 계산기투자금과 월 잔액을 기준으로 단순 회수기간을 계산

브랜드·업종 비교

브랜드 조건 찾기업종·공개비용·가맹점 수·점포 증감 조건으로 브랜드를 좁혀 보기업종 중앙값 비교선택 브랜드 공개비용을 같은 업종의 공식 매칭 중앙값과 비교가맹점 개·폐업률 계산기기준 점포 수와 신규·종료·해지 건수를 같은 분모로 계산

계산 결과를 읽는 기준

계산 결과가 실제 계약금액과 같은가요?

아닙니다. 공개자료와 사용자가 입력한 가정을 정리하는 도구이며 실제 견적·계약서·최신 정보공개서를 다시 확인해야 합니다.

정보가 없으면 0으로 계산하나요?

공식 공개값의 누락은 0과 구분합니다. 값이 필요한 비교·필터에서는 정보 없음으로 처리합니다.

월 손익과 평균매출은 같은 의미인가요?

아닙니다. 평균매출 공개지표는 수익이 아니며 월 손익 도구는 사용자가 입력한 비용 가정으로 단순 영업잔액을 계산합니다.
