월 손익 계산기

월매출·원가율·플랫폼비·로열티·인건비·임차료를 입력해 영업잔액과 손익분기 매출을 계산합니다.

1 매출 입력2 비용 입력3 손익 확인

계산식

월 단순 영업잔액 = 월매출 × (1 - 원가율 - 플랫폼비율 - 로열티비율) - 인건비 - 임차료 - 공과금 - 기타고정비

손익분기 매출 = 월 고정비 ÷ (1 - 비율비용 합계)

계산에서 빠지는 항목

부가가치세, 종합소득세·법인세, 감가상각, 대출 원리금, 카드정산 시점, 점주 인건비 처리, 폐기·로스, 프로모션 분담, 계절성 등은 별도입니다. 결과가 양수여도 실제 수익이나 사업 성과를 보장하지 않습니다.

브랜드 공개데이터와 분리하는 이유

공정위 평균매출은 비용을 빼기 전 매출 자료이고, 개별 점포의 실제 원가·임대료·인건비는 다릅니다. 따라서 브랜드 데이터와 사용자의 손익 가정을 같은 숫자로 섞지 않습니다.

계산 예

입력

월매출·원가율·플랫폼비율·로열티·인건비·임차료를 직접 입력합니다.

출력

단순 영업잔액과 입력 가정에 따른 손익분기 매출을 계산합니다.

자주 묻는 질문

이 결과가 예상 순이익인가요?

아닙니다. 사용자가 입력한 항목만 반영한 단순 시뮬레이션이며 세금·대출·감가상각·점주 인건비 등은 별도입니다.

브랜드 평균매출을 그대로 넣어도 되나요?

평균매출은 개별 점포 매출을 보장하지 않습니다. 사용 목적에 맞는 가정값을 별도로 입력해야 합니다.

손익분기 매출보다 높으면 창업해도 되나요?

그렇게 판단할 수 없습니다. 계산 결과는 의사결정을 대신하지 않으며 실제 비용과 계약조건을 추가로 확인해야 합니다.

결과가 양수면 수익이 보장되나요?

아닙니다. 실제 영업 결과와 사업 성과를 보장하지 않습니다.
