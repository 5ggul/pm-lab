정보공개서 비용 항목 해독기

정보공개서의 가맹금·교육비·보증금·기타비·인테리어 항목을 입력하면 성격과 점포별 추가확인 항목을 나눠 보여줍니다.

입력 항목 합계0만원
가맹금 관련 4개 항목
0만원
인테리어 입력액
0만원
가장 큰 입력항목
입력 전

이 결과는 입력한 다섯 항목의 단순 합계입니다. 임대보증금·권리금·철거·전기증설·냉난방·초도물품·운전자금 등이 빠질 수 있으므로 실제 총투자금으로 보지 않습니다.

금액은 모두 만원 단위로 입력합니다. 입력값은 브라우저 안에서만 계산하며 서버로 전송하지 않습니다.

계산식

입력 합계 = 가맹비 + 교육비 + 보증금 + 기타비용 + 인테리어 입력액

계산 예

가맹금

브랜드 사용·계약 관련 비용으로 분류

인테리어

기준면적·평당단가·별도공사 확인 항목 표시

이 계산에 자동으로 포함되지 않는 비용

  • 점포 임대보증금과 권리금
  • 철거·전기증설·냉난방·소방·외부공사
  • 초도물품과 오픈 초기 운전자금
  • 원문에서 기타비용에 이미 포함된 항목의 중복 여부

자주 묻는 질문

기타비용은 무엇인가요?

원문 항목 정의와 세부 내역을 확인해야 합니다.

보증금은 반환되나요?

계약상 반환 조건을 확인해야 합니다.

인테리어 항목만으로 견적이 나오나요?

아닙니다. 점포 현장 조건이 필요합니다.

해독기가 계약을 대신 검토하나요?

아닙니다. 항목 이해를 돕는 도구입니다.
