계산 기준

창업비용은 공공데이터포털 원본의 천원 단위를 만원 단위로 변환합니다. 점포 증감률은 (현재 가맹점 - 이전 가맹점) ÷ 이전 가맹점 × 100으로 계산합니다. 업종 중앙값은 같은 카탈로그 업종에서 공식 레코드가 매칭된 브랜드의 유효값만 사용합니다.

누락값은 0으로 바꾸지 않습니다. 신규·종료·해지는 별도 항목으로 유지하고, 평균매출 공개지표를 순이익으로 표현하지 않습니다. 기준연도나 면적 기준이 다르면 비교 경고가 필요합니다.
