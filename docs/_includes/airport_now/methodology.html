공항나우
공항인천 도착데이터

지연률 계산 기준

공식 상태값과 자체 계산값을 같은 개념으로 섞지 않습니다.

지연 판정

공식 API에 지연 상태가 있으면 공식 상태를 우선합니다. 공식 상태가 없고 예정시각과 실제 또는 변경시각을 확인할 수 있을 때만 예정시각 대비 15분 초과를 보조 기준으로 사용합니다.

분모

상태가 확인되지 않는 항공편은 분모에서 제외합니다. 공동운항은 실제 운항편 기준으로 중복 제거하고 마케팅 편명은 검색용 별칭으로 따로 저장합니다. 출발 지연률과 도착 지연률은 서로 섞지 않습니다.

최근 4주 기준선

공항별로 최근 4주의 같은 요일·같은 1시간대·같은 출발/도착 구분을 비교합니다. 예를 들어 16시대는 예정시각 16:00~16:59인 항공편입니다. 실제 분모가 충분하지 않으면 평균과 “평소보다 높음/낮음” 라벨을 표시하지 않습니다.

이력 저장

같은 항공편을 반복 조회해도 상태·예정/변경/실제시각·터미널·게이트·수하물·지연분처럼 의미 있는 값이 바뀔 때만 이벤트 이력을 추가합니다. 이를 바탕으로 시간대·노선·편명 단위 집계를 만듭니다.

기상 데이터

METAR는 API 수신시각이 아니라 실제 관측시각을 기준으로 최신 여부를 판정합니다. HTTP 200이어도 관측이 오래됐으면 현재 기상으로 표시하지 않습니다. 기상 상태와 지연의 인과관계는 공식 원인 데이터가 없는 한 추정하지 않습니다.

현재 Preview

현재 화면에는 검증된 인천 도착편 스냅샷과 관측시각까지 검증한 METAR만 실제 데이터로 표시합니다. 인천 출발과 한국공항공사 비인천 운항편은 공식 API 스펙과 저장 파이프라인까지 구현됐지만 서비스키 활용권한이 확인되기 전까지 실제 수치로 표시하지 않습니다.
