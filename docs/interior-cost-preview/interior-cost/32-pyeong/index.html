32평 비용은 총액보다 네 조건을 먼저 맞춥니다

같은 32평이어도 욕실 개수, 샷시 교체 범위, 주방 길이와 구성, 철거 범위가 다르면 업체 총액은 크게 달라집니다. 평수 하나만으로 시장가격을 만들기보다 아래 네 조건을 먼저 같은 기준으로 맞춰야 실제 견적 비교가 가능합니다.

현재 지역·공사범위·자재등급·VAT 조건을 표준화한 실제 민간 견적 표본이 충분하지 않아 32평 평균·중앙값·P25/P75를 표시하지 않습니다. 숫자를 비워두는 대신 사용자가 받은 견적서에서 빠진 항목과 업체별 조건 차이를 확인할 수 있게 연결합니다.

공종별 비용은 평수가 아니라 실제 수량으로 봅니다

32평은 약 105.79㎡의 공급면적 단순 환산값일 뿐, 욕실 벽·바닥 면적이나 도배·바닥·목공·단열의 실제 작업량과 같지 않습니다. 도면이나 견적서에 수량이 있으면 아래 공종별 페이지에서 공개 참고단가와 조달청 자재가격을 별도 레이어로 확인합니다.

자주 묻는 질문

32평이면 욕실이 두 개인가요?

평수만으로 가정하지 않습니다. 실제 평면과 견적서의 욕실 개수를 기준으로 비교합니다.

32평 공급면적을 도배나 바닥 면적으로 써도 되나요?

아닙니다. 공급면적과 실제 시공면적은 다르므로 견적서·도면의 작업 수량을 사용해야 합니다.

공사비지수 138.59를 32평 가격에 곱하면 되나요?

안 됩니다. 건설공사비지수는 시간에 따른 투입가격 변화 지표이며 32평 민간 인테리어 시장가격이 아닙니다.
