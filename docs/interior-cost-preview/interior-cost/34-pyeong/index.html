자주 묻는 질문

34평이면 욕실 수를 어떻게 봐야 하나요?

실제 평면과 견적서에 적힌 욕실 개수를 기준으로 봅니다. 평수만으로 욕실 수를 가정하지 않습니다.

샷시 제외 견적은 어떻게 비교하나요?

비교 대상 견적에서도 샷시를 제외하거나 별도 항목으로 분리한 뒤 총액을 봅니다.

VAT가 빠져 있으면 어떻게 하나요?

포함/별도 여부를 확인하고 동일 기준으로 환산한 뒤 비교합니다.

데이터 기준

이 페이지는 견적 항목을 같은 기준으로 읽기 위한 편집 가이드입니다. 실제 계약금액이나 시장평균을 단정하지 않습니다. 숫자를 표시할 때는 표본 수·기간·지역·포함조건을 함께 공개합니다.
