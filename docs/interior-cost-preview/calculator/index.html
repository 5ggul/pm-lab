계산 결과를 읽는 법

첫 번째 합계는 사용자가 직접 넣은 수량과 단가의 합계입니다. 공사비지수 환산은 기간별 건설 직접공사비 변화를 참고하는 계산이고, 공공 참고단가는 같은 공종의 규격과 단위를 확인하는 비교축입니다. 서로 다른 성격의 숫자를 하나의 시장 평균으로 합치지 않습니다.

자주 묻는 질문

왜 평당 가격을 자동으로 넣지 않나요?

공사 범위와 자재 사양이 다른 견적을 한 개의 평당 단가로 고정하면 실제 비교에 필요한 조건 차이가 사라지기 때문입니다.

VAT 10% 추가는 시장 평균인가요?

아닙니다. 사용자가 입력한 금액에 산술적으로 10%를 더하는 기능입니다.

공공 참고단가보다 비싸면 과다 견적인가요?

그렇게 판정할 수 없습니다. 공공 단가와 민간 인테리어 견적은 적용 범위와 포함 비용이 다를 수 있으므로 같은 공정·규격·제외조건을 확인한 뒤 참고해야 합니다.

출처와 기준

공사비지수와 공공 참고단가는 공식 공표 자료를 사용하며, 세부 페이지에서 기준 시점과 적용 범위를 확인할 수 있습니다.
