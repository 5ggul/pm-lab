표시 총액에 포함된 금액인지 별도인지 먼저 확인합니다.

폐기물 별도는 이상한 견적인가요?

별도 자체보다 추가금 산정 기준과 반출 조건이 명확한지가 중요합니다.

욕실 1식이면 비교가 불가능한가요?

세부 범위와 사양을 확인하기 전에는 다른 견적의 세분화 금액과 직접 비교하기 어렵습니다.
