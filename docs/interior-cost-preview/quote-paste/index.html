사용 기준

견적검수실은 OFFICIAL·REFERENCE·QUOTE·CALCULATED 데이터를 서로 다른 종류로 구분합니다. 공공 표준시장단가는 민간 아파트 인테리어 시장평균이나 적정가격 판정용이 아니며, 실제 민간 견적의 전체 가격분포는 N 30 이상, 지역·평수·공종 같은 세그먼트 가격분포는 각 셀 N 20 이상일 때만 공개합니다. 지역×평수는 별도 집계 차원으로 관리하고 다른 지역이나 전국 데이터를 빈 셀에 대입하지 않습니다. 견적 붙여넣기 도구는 텍스트를 브라우저 안에서 분류하며 OCR이나 서버 업로드를 사용하지 않습니다. 개인정보와 업체 식별정보는 익명 견적 통계 스키마에서 허용하지 않습니다. 이 사이트는 현재 운영 배포 전 프리뷰이므로 모든 페이지의 검색 색인을 막고 있으며 운영 robots 변경은 소유자 검수 후 별도 단계로 진행합니다.
