검증 전

동일 sample_id는 차단합니다. 다른 ID라도 월·지역·평수·주택유형·범위·욕실·창호·VAT·폐기물·총액 조합이 같으면 중복 의심으로 검토합니다. 전용평수가 공급평수보다 큰 경우, 공종별 금액 합이 총액보다 큰 경우도 검토 대상으로 표시합니다. 이 상태만으로 행을 자동 삭제하거나 시장에서 비싸고 싸다고 판단하지 않습니다.

운영자 비공개 검사

브라우저 도구는 1차 정리용입니다. 실제 집계 전에는 비공개 환경에서 audit-quote-batch-v12.mjs를 실행해 스키마, 잠재 중복, 구조적 검토 항목과 데이터셋 내부 3×IQR 이상치를 확인합니다. 감사 결과에는 검토용 sample_id가 포함될 수 있으므로 public docs에 저장하지 않습니다.
