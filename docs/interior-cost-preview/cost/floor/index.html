바닥 공사

바닥·마루 비용

바닥 견적은 평수보다 실제 시공면적, 자재 종류, 기존 바닥 철거와 바탕 보수·걸레받이 마감까지 같은 조건으로 비교합니다.

바닥 견적에서 확인할 항목

항목확인 내용
시공 면적방·거실·주방 등 실제 시공 공간과 제외 공간을 구분하고 ㎡ 기준 수량을 확인합니다.
자재강마루·원목마루·장판 등 종류와 제품 규격, 두께, 패턴을 확인합니다.
기존 바닥 철거기존 마루·장판·타일 제거와 접착제 제거, 폐기물 반출 포함 여부를 봅니다.
바탕 보수단차·균열·수평 보정 등 하부 상태에 따른 보수 범위가 포함되는지 확인합니다.
마감걸레받이, 문턱, 문 하부 조정, 현관·주방 연결부 마감 범위를 봅니다.

공급평수와 바닥 시공면적은 다릅니다

욕실·발코니·붙박이 가구 아래처럼 시공하지 않는 공간이 있을 수 있고 확장 여부에 따라 실제 면적이 달라집니다. 업체별 견적을 비교할 때는 평수 대신 동일한 시공면적과 같은 자재 사양으로 맞추세요.

철거와 바탕 보수를 분리해서 보기

새 바닥재 시공비만 표시된 견적과 기존 마감 철거·접착제 제거·수평 보수까지 포함된 견적은 같은 범위가 아닙니다. 추가 가능성이 있는 작업을 별도 항목으로 확인하면 총액 차이를 이해하기 쉽습니다.

자주 묻는 질문

32평 아파트면 바닥도 32평을 시공하나요?

아닙니다. 실제 시공 공간을 기준으로 면적을 확인해야 합니다.

마루 철거비가 없으면 새 마루 금액에 포함된 건가요?

미기재만으로 포함을 판단하지 말고 철거·폐기물과 바탕 정리 범위를 확인하세요.

자재 이름이 같으면 같은 조건인가요?

제품 규격과 두께, 색상·패턴, 시공 방식이 다를 수 있으므로 상세 사양을 확인해야 합니다.
