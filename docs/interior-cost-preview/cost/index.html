공사별 비용

공사별 인테리어 비용

총액보다 실제 작업 수량, 자재 사양, 철거·보수 범위와 별도비를 공종별로 나눠 확인합니다.

공사 종류 선택

욕실 인테리어 비용

철거·폐기물·방수·타일·도기·수전·배관 이동을 분리해 확인합니다.

주방 인테리어 비용

가구 길이, 상판, 아일랜드·키큰장, 철거, 배관·전기 이동 범위를 봅니다.

샷시·창호 교체 비용

창 개수와 치수, 프레임·유리 사양, 철거·양중·마감 포함 여부를 확인합니다.

도배 비용

실제 벽·천장 면적, 기존 벽지 제거, 바탕면 보수와 합지·실크 사양을 봅니다.

바닥·마루 비용

실제 시공면적, 기존 바닥 철거, 자재 종류, 걸레받이·문턱 마감을 확인합니다.

철거·폐기물 비용

철거 범위, 반출 거리, 장비·엘리베이터·양중 조건을 나눠 봅니다.

전기·조명 비용

회로, 콘센트·스위치 개수, 증설, 분전반과 전용회로 범위를 확인합니다.

목공 비용

천장, 가벽, 몰딩, 문틀, 간접조명 구조 등 작업 범위를 분리합니다.

단열 시공 비용

단열재 종류와 두께, 실제 작업면적, 부착 방식과 마감 복구 범위를 확인합니다.

공사별 견적에서 공통으로 볼 것

항목확인할 내용
수량㎡, m, 개, 회로, 식 등 실제 계산 기준이 견적에 적혀 있는지 확인합니다.
사양제품명만이 아니라 규격, 두께, 등급, 유리·상판·벽지 종류처럼 가격을 바꾸는 조건을 봅니다.
철거·보수기존 마감 제거와 바탕 보수, 폐기물 반출이 본 공사 금액에 포함되는지 확인합니다.
별도비양중, 주차, 폐기물, 현장관리비, VAT처럼 총액 밖에 남아 있는 항목을 확인합니다.

공공 참고단가와 같이 보기

일부 타일·방수·도배·도장·목공·단열 공정은 공공 표준시장단가에서 유사 공종을 확인할 수 있습니다. 다만 공공 건설 예정가격 참고자료이므로 민간 아파트의 시장 평균이나 업체 적정가격으로 그대로 사용하지 않습니다.
