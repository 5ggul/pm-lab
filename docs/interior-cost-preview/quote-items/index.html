자주 묻는 질문

표준 항목 이름으로 견적서를 다시 써야 하나요?

원문 견적서를 바꿀 필요는 없습니다. 비교용 표에서만 표준 항목을 사용하고 원래 표현을 함께 기록하면 됩니다.

단위가 서로 다르면 어떻게 비교하나요?

㎡·평, m·식처럼 단위가 다르면 실제 수량 산정 기준부터 확인합니다. 임의로 환산하기 전에 무엇을 한 단위로 셌는지 업체에 확인하는 편이 정확합니다.
