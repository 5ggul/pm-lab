견적 범위 확인

인테리어 견적 1식 해체

‘욕실 1식’, ‘주방 1식’, ‘샷시 1식’의 금액을 임의로 쪼개지 않고, 업체에 확인해야 할 세부 범위·수량·사양 질문을 만듭니다.

서버 전송 없음브라우저에서 계산임의 평균 배분 없음

1식 표기가 문제라기보다 비교 정보가 부족할 수 있습니다

1식은 여러 작업을 한 묶음으로 표현하는 방식입니다. 철거·폐기물·자재·수량·설비 이동처럼 포함 범위가 확인되면 사용할 수 있지만, 업체마다 1식의 내용이 다르면 총액만으로 비교하기 어렵습니다.

욕실 1식에서 확인할 것

기존 마감 철거와 폐기물, 방수 범위, 벽·바닥 타일, 도기·수전, 욕실장, 천장·환풍기, 배관·전기 이동과 문틀 주변 마감이 어디까지 포함되는지 확인합니다.

주방 1식에서 확인할 것

상·하부장 길이와 배치, 도어·몸통·상판 사양, 키큰장·아일랜드·가전장, 기존 주방 철거, 급배수·전기 이동과 별도 구매 품목을 나눠 봅니다.

샷시 1식에서 확인할 것

교체 창 위치·개수·치수, 프레임·유리 사양, 기존 창 철거, 양중, 폐기물, 실리콘·단열과 주변 마감 복구 범위를 확인합니다.

자주 묻는 질문

1식 견적은 피해야 하나요?

무조건 피할 표현은 아닙니다. 상세내역이나 계약 문서에서 포함 범위와 사양을 확인할 수 있는지가 중요합니다.

표시 금액을 공정별로 자동 배분해도 되나요?

실제 세부 견적 근거가 없다면 임의 비율로 배분하지 않는 편이 안전합니다. 이 도구도 입력 금액을 시장 평균 비율로 나누지 않습니다.
