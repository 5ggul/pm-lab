    오류 수정출처, 계산식, 분류 오류를 수정 이력에 기록.

    공종별 금액, 자재 사양, 철거·폐기·양중·현장관리비, VAT 포함 여부를 분리해 확인합니다.

    추가 공사

    추가 금액이 발생하는 조건과 승인 방식, 변경 견적서 발행 여부를 계약 전에 확인합니다.

    일정

    착공일, 완료 예정일, 공정 변경 시 일정 조정 기준을 계약서에 남깁니다.

    운영 정보

    인테리어 공사비와 견적 항목을 공종·수량·사양 기준으로 정리하는 데이터 서비스입니다.

    업체 중개·시공 계약·법률 자문을 제공하지 않습니다.

    문의

    데이터 오류, 견적 항목 분류, 출처 정정 요청을 받습니다.

    연락처는 운영 도메인 확정 후 실제 수신 주소로 연결합니다.

    개인정보처리방침

    현재 견적 입력값은 브라우저 저장소에만 저장되며 서버로 전송하지 않습니다.

    파일 업로드와 개인정보 수집 기능은 제공하지 않습니다.

    이용약관

    표시 금액과 비교 결과는 참고용입니다. 실제 계약 금액은 현장 조건, 자재, 수량, 업체 조건에 따라 달라질 수 있습니다.
