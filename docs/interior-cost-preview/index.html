    가격 데이터 계층

    1. 공공 가격·단가자재·시공 원가 기준 자료
    2. 소비자 공종 분류철거·욕실·주방·바닥 등으로 매핑
    3. 수량·사양 환산㎡·m·개·실 기준으로 변환
    4. 민간 견적 표본 보정동일 조건의 실제 견적이 확보된 범위에서만 사용
    5. 소비자 표시모델 계산과 실제 견적 분포를 구분
