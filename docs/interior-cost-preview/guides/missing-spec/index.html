견적 사양 확인

견적서에 제품·규격·수량이 없을 때 확인할 것

‘타일’, ‘강마루’, ‘샷시’, ‘수전’처럼 품목명만 적혀 있으면 같은 공종이라도 실제 납품 사양을 비교하기 어렵습니다.

욕실타일, 도기, 수전, 욕실장, 천장, 환풍기 제품·규격과 공사 범위

사진만 첨부돼 있으면 충분한가요?

참고 이미지는 디자인 방향을 맞추는 데 도움이 되지만 정확한 제품과 규격을 대신하지 못합니다. 비슷하게 보이는 제품도 재질·크기·등급이 다를 수 있으므로 계약 단계에서는 모델명이나 동등 사양 기준을 문자로 남기는 편이 좋습니다.

‘동급 제품’ 표기는 기준을 같이 적습니다

특정 제품이 단종되거나 수급이 어려운 상황에 대비해 동급 대체를 허용할 수 있습니다. 이때는 가격만 비슷한 제품이 아니라 재질, 규격, 성능, 색상 등 어떤 기준을 유지할지 정해 두면 변경 과정에서 해석 차이를 줄일 수 있습니다.

사양이 없는 견적을 비교하는 순서

단계확인
1제품·규격·수량이 빠진 항목을 표시합니다.
2업체별로 같은 질문을 보내 사양을 보완합니다.
3대체 가능 조건과 추가금 발생 기준을 확인합니다.
4사양을 맞춘 뒤 공종별 금액과 총액을 비교합니다.

자주 묻는 질문

브랜드명만 있으면 충분한가요?

같은 브랜드 안에서도 제품군과 규격이 다양할 수 있어 모델·규격까지 확인하는 편이 좋습니다.

계약 후 제품을 바꾸면 어떻게 하나요?

변경할 제품과 금액 증감, 공정 영향, 승인 주체를 작업 전에 서면으로 남기면 분쟁 가능성을 줄일 수 있습니다.
