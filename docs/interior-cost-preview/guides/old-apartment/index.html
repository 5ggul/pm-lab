구축 리모델링

구축 아파트 인테리어, 추가공사는 어디서 생기나

‘구축이라서 몇 % 추가’처럼 일괄 가산하지 말고 철거 전 확인 가능한 항목과 철거 후 발견되는 항목을 나눠 견적과 추가공사 기준을 확인합니다.

공사 전에 확인할 항목

항목확인할 내용
전기분전반 상태, 회로 구성, 콘센트·조명 추가 위치, 고용량 가전 사용 계획
급배수주방·욕실 설비 위치 변경 여부, 노출된 배관 상태와 누수 흔적
샷시 주변창 주변 균열·결로 흔적, 실리콘·마감 상태와 교체 범위
욕실누수 흔적, 배수 위치, 기존 덧방 여부와 철거 범위
확장부기존 확장 여부, 바닥·벽·천장 연결 상태와 단열 확인

철거 후에야 확인되는 항목

마감재를 걷어낸 뒤 바탕면 손상, 부식된 배관, 예상과 다른 배선 경로, 누수 흔적 등이 드러날 수 있습니다. 이처럼 사전에 확정하기 어려운 작업은 추가공사 발생 조건과 승인 절차를 계약 전에 정해 두는 것이 중요합니다.

발견 가능 항목확인 방법
바탕면 손상보수 범위와 마감 복구 방법을 사진으로 확인
배관 문제교체 구간·재료·연결부와 추가 작업 범위 확인
전기 문제배선 교체·회로 추가가 필요한 이유와 범위 확인
누수·습기원인을 먼저 확인하고 방수·배관·외벽 등 공사 범위를 구분

견적서에 미리 적어둘 문구

‘철거 후 상태에 따라 별도’만 적기보다 어떤 상황이 추가공사 대상인지, 작업 전에 사진과 금액을 공유하는지, 발주자 승인 후 진행하는지까지 정하면 변경 과정이 명확해집니다.

자주 묻는 질문

오래된 아파트면 전기 전체 교체가 필수인가요?

준공연도만으로 단정할 수 없습니다. 현재 설비 상태와 사용 계획, 점검 결과를 바탕으로 필요한 범위를 정해야 합니다.

철거 후 발견된 문제는 무조건 추가금인가요?

기존 계약 범위와 발견된 상태에 따라 달라질 수 있습니다. 작업 전 추가 범위와 금액을 확인하고 합의한 뒤 진행하는 절차가 중요합니다.
