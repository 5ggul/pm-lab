계약 전 견적 확인

인테리어 견적의 자재·노무·경비·관리비는 어떻게 보나

업체마다 금액을 묶는 방식이 다르므로 항목명이 같은지보다 어떤 작업과 비용이 총액에 포함됐는지를 확인해야 합니다.

견적 금액을 나눠 보는 기준

구분확인할 내용
자재마감재·설비·부자재의 제품, 규격, 수량과 납품 범위
노무철거·목공·전기·타일·도배 등 실제 시공 작업 범위
경비운반, 양중, 폐기물, 보양, 장비, 주차 등 현장 조건에 따른 비용
현장관리공정 조율, 자재 입고, 작업자·일정 관리 등 관리 업무와 산정 방식
VAT각 항목 또는 최종 총액에 부가세가 포함됐는지 확인

모든 견적이 자재비와 노무비를 따로 적는 것은 아닙니다

‘도배 1식’, ‘욕실 전체’, ‘주방가구 제작·설치’처럼 자재와 시공이 한 항목으로 묶일 수 있습니다. 이 경우 세부 금액을 반드시 분리해야 하는 것은 아니지만 제품·수량·작업 범위와 별도비가 확인돼야 다른 견적과 비교할 수 있습니다.

총액에 포함된 비용을 먼저 표시합니다

항목확인 표시
자재 납품포함 / 별도 / 발주자 구매
시공포함 / 별도
운반·양중포함 / 별도 / 조건부
폐기물포함 / 별도 / 추가 반출 기준
현장관리포함 / 별도 / 정액·비율
VAT포함 / 별도 / 미기재

추가공사 때 같은 구조로 다시 봅니다

공사 중 사양이나 범위가 바뀌면 새 자재비만 볼 것이 아니라 빠지는 기존 자재·작업의 감액, 추가 노무, 운반·폐기물, 관리비와 VAT가 어떻게 변하는지도 함께 확인합니다.

자주 묻는 질문

자재비와 노무비가 분리되지 않으면 나쁜 견적인가요?

그 자체만으로 판단하기 어렵습니다. 묶인 항목의 제품·수량·시공 범위와 포함·별도 조건이 명확한지가 더 중요합니다.

경비와 현장관리비가 둘 다 있으면 중복인가요?

항목명이 다르다는 이유만으로 중복이라고 볼 수 없습니다. 각 항목에 어떤 업무와 비용이 들어가는지 확인해 겹치는 부분이 있는지 비교해야 합니다.
