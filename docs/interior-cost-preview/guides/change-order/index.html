공사 변경 관리

추가공사·변경공사, 작업 전에 무엇을 합의해야 하나

공사 중 변경이 생기면 ‘추가’라는 말만 남기지 말고 변경 사유, 작업 범위, 수량·사양, 증감 금액, VAT와 일정 영향을 기존 계약과 구분해 기록합니다.

추가금만 있고 감액이 빠지지 않았는지 봅니다

기존 공사를 빼고 다른 사양으로 바꾸는 경우에는 새 작업 비용만 더할 것이 아니라 빠진 기존 항목의 감액도 함께 확인해야 합니다. 변경 전·후 금액을 나란히 두면 실제 증감액을 읽기 쉽습니다.

작업 후 통보보다 작업 전 승인이 중요합니다

현장에서 바로 결정해야 하는 상황이라도 가능한 범위에서 사진, 변경 내용, 예상 증감액을 먼저 공유하고 승인 기록을 남기는 편이 좋습니다. 긴급 안전조치처럼 사전 합의가 어려운 경우에는 작업 사유와 범위를 즉시 기록해 두는 것이 도움이 됩니다.

자주 묻는 질문

구두로 합의해도 되나요?

나중에 내용이 달라질 수 있으므로 작업 범위와 금액은 문자·메일·합의서처럼 다시 확인할 수 있는 형태로 남기는 편이 좋습니다.

철거 후 예상 못 한 문제가 나오면 어떻게 하나요?

사진과 상태를 확인하고 기존 계약에 포함되는지 판단한 뒤, 별도 작업이면 범위·금액·일정을 합의하고 진행하는 순서가 명확합니다.
