부분수리 vs 올수리, 견적 구조가 다른 이유

부분수리는 공사 면적이 작더라도 기존 마감 보호와 연결부 복구, 작업팀 재투입 같은 비용이 남아 올수리 총액을 면적 비율로 단순 환산하기 어렵습니다.

부분수리에서 따로 확인할 비용

항목부분수리에서 확인할 내용
보양남겨둘 바닥·가구·문·공용부를 보호하는 범위
부분 철거철거 경계와 기존 마감 손상 방지, 폐기물 반출
연결부 마감새 자재와 기존 자재가 만나는 문턱·몰딩·벽·천장 복구
설비 연결기존 배관·전기와 새 설비를 연결하는 작업
공정 분할작업팀이 여러 번 들어오거나 소량 작업으로 나뉘는지 확인
현장관리작은 공사라도 일정 조율·보양·청소·관리 비용이 발생하는지 확인

올수리가 항상 단가가 더 높은 것은 아닙니다

올수리는 총 작업량이 크지만 철거와 마감 범위를 한 번에 계획할 수 있습니다. 반대로 부분수리는 남길 부분을 보호하고 기존 마감과 새 마감을 연결해야 해 공종별 최소 작업비나 재방문 비용이 상대적으로 크게 보일 수 있습니다.

자주 묻는 질문

집의 절반만 고치면 올수리의 절반 정도인가요?

단순 비례로 보기 어렵습니다. 철거 준비, 보양, 폐기물, 출장·관리와 연결부 마감처럼 면적과 비례하지 않는 작업이 남을 수 있습니다.

부분수리 견적에서 꼭 적어야 할 경계는 무엇인가요?

철거할 곳과 남길 곳, 새 마감이 끝나는 위치, 기존 설비와 연결되는 지점을 도면·사진·문장으로 명확히 하는 것이 좋습니다.
