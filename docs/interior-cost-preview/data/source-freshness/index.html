데이터 사용 기준

견적검수실은 공식 통계, 공공 예정가격 참고값, 사용자가 입력한 계산 결과, 익명 민간 견적 집계를 서로 다른 데이터 종류로 관리합니다. 공공 표준시장단가는 민간 아파트 인테리어 시장평균이나 적정가격으로 바꾸지 않습니다. 실제 견적 가격분포는 전체 검수 표본 N 30 이상, 지역·평수·공사범위 같은 세부 셀 N 20 이상이라는 사이트 공개 기준을 충족한 경우에만 P25·중앙값·P75를 표시합니다. 평균값은 공개하지 않으며 기준 미달 셀은 N과 보류 상태만 표시합니다.

견적 데이터 수집 스키마는 성명, 전화번호, 이메일, 상세주소, 업체명, 사업자번호, 계좌, 서명 같은 식별정보 열을 허용하지 않습니다. 브라우저 수집 도구는 서버 업로드 없이 로컬에서 익명 행을 만든 뒤 CSV를 사용자가 직접 내보내며, 운영자는 원본 파일을 공개 저장소 밖에서 검증합니다. 공개 산출물에는 원본 행 대신 집계 통계, 데이터 품질, 커버리지, 공개 기준까지 남은 표본 수만 포함합니다.

공식 데이터 감시기는 건설공사비지수, 건설업 임금실태조사, 표준시장단가의 새 공표 기간을 탐지하지만 숫자를 자동으로 덮어쓰지 않습니다. 새 기간이 감지되면 업데이트 필요 상태만 기록하고 원문·기간·단위를 확인한 뒤 검증 데이터에 반영합니다. 현재 는 운영 전환 전 검수 단계이므로 모든 페이지를 로 유지하며 robots 변경과 운영 도메인 배포는 사용자 승인 후 별도로 수행합니다.
