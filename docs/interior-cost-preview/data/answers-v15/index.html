정적 HTML에서 H1 개수, 이미지 alt, 빈 버튼, 표 헤더처럼 빌드 단계에서 확인 가능한 치명적 누락을 검사합니다.

근거/도구
SEO

운영 sitemap은 하나만 쓰나요?

프리뷰에서는 실제 sitemap을 바꾸지 않고 core·tools·content·data 네 묶음으로 분할한 시뮬레이션을 만들어 검수합니다.

근거/도구
SEO

canonical과 sitemap 역할은 같은가요?

canonical은 페이지의 대표 URL을 선언하고 sitemap은 색인 후보 URL 발견을 돕습니다. v13 감사에서는 둘을 별도로 검사합니다.

근거/도구
AEO

AI 답변 근거 링크는 어디를 사용하나요?

답변 레코드의 source 또는 evidence URL을 실제 도구·데이터·방법론 페이지에 연결하고 빈 근거 링크가 남지 않도록 검사합니다.

근거/도구
광고

v13에서 광고를 실제로 켜나요?

아니요. v12 광고 슬롯 계획은 유지하지만 실제 광고 스크립트와 운영 활성화는 사용자 승인 전까지 하지 않습니다.

근거/도구
SEO

표본 없는 지역 페이지가 sitemap에 들어가나요?

운영 시뮬레이션에서 지역 N 기준을 통과하지 못한 지역·지역×평수 페이지는 index 후보와 sitemap 분할에서 제외합니다.

운영

v13 통과 후 바로 운영 배포되나요?

아니요. v13은 프리런치 감사이며 robots·sitemap·광고·운영 도메인 변경은 사용자 승인 후 별도 작업입니다.

근거/도구
운영

v15는 무엇이 달라졌나요?

사용자용 핵심 페이지와 production 검색 후보를 분리하고 이전 감사·운영 페이지는 최종 검색 후보에서 제외했습니다.

근거/도구
SEO

운영 sitemap에는 어떤 페이지가 들어가나요?

사용자 가치가 있는 도구·평수·공종·가이드·공식 데이터·최신 답변 페이지만 후보로 둡니다.

근거/도구
SEO

이전 답변 허브도 모두 색인하나요?

아니요. v10~v13 답변 허브는 기록으로 남기고 최신 v15 허브만 production 후보로 둡니다.

근거/도구
SEO

OG와 meta description은 어떻게 관리하나요?

production 후보마다 title·description·canonical·Open Graph·Twitter 메타를 같은 URL 역할로 맞춥니다.

AEO

production 후보의 구조화데이터 기준은?

production 후보는 페이지 역할을 설명하는 WebPage·CollectionPage·WebApplication·Dataset 계열 근거를 가져야 합니다.

근거/도구

실제 견적 표본은 어떻게 늘리나요?

핵심 페이지에서 익명 견적 행 만들기로 연결하고 로컬 CSV를 비공개 검수한 뒤 집계만 공개합니다.

근거/도구
SEO

개인정보처리방침도 sitemap에 넣나요?

정책 페이지는 접근 가능하게 유지하지만 검색 유입 목적의 production sitemap 후보에서는 제외합니다.

근거/도구
운영

실제 도메인으로 바꾸면 무엇을 다시 써야 하나요?

canonical·OG URL·schema URL·sitemap·robots의 sitemap 위치를 production origin으로 다시 생성합니다.
