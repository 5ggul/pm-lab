1. 건설공사비지수

한국건설기술연구원 공사비원가관리센터가 공표하는 지수입니다. 사이트에서는 기준월, 기준연도, 월별 값과 변화율을 표시하고 과거·현재 시점의 원가 환경을 비교하는 데 사용합니다.

KICT 공사비원가관리센터

2. 건설업 임금실태조사

대한건설협회가 공표하는 지정통계입니다. 2026년 하반기 자료는 132개 직종 일평균임금 282,737원으로 공표됐습니다. 사이트에서는 전체 건설업 임금 변화의 참고자료로 사용합니다.

대한건설협회 2026 하반기 공표자료

3. 표준시장단가

국토교통부가 발표하고 건설기술정보시스템(CODIL)에서 제공하는 공공 건설공사 예정가격 관련 자료입니다. 사이트에서는 인테리어와 가까운 공종의 작업 정의, 규격, 단위, 재료 포함·제외 조건을 확인하는 참고자료로 사용합니다.
