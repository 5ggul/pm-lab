공개 업로드 엔드포인트 없음 · 익명 CSV · 원본 행 비공개 · 집계만 공개

받는 정보

견적 월, 시도, 공급·전용 평수, 주택유형, 올수리/부분, 욕실 수, 창호 범위, VAT·폐기물 상태, 총액과 선택적인 공종별 금액입니다. 실제 가격분포를 같은 조건으로 집계하는 데 필요한 최소 범위만 사용합니다.

받지 않는 정보

성명, 업체명, 전화번호, 이메일, 상세주소, 사업자번호, 계좌, 서명, 계약서 원본 식별정보는 스키마에 넣지 않습니다. 해당 열이 CSV에 있으면 비공개 감사 단계에서 차단합니다.

현재 에서의 전달

공개 사이트에는 서버 제출 기능을 두지 않았습니다. 익명 행 만들기 또는 CSV 대량 검수로 정리한 후 운영자가 승인한 비공개 수집 경로에서만 원본 CSV를 취급합니다.

공개되는 것

원본 행이 아니라 N, P25, 중앙값, P75와 커버리지 상태만 공개합니다. 전체 N≥30, 세부 셀 N≥20 미만이면 가격은 보류합니다. 평균값과 업체 순위는 공개하지 않습니다.
