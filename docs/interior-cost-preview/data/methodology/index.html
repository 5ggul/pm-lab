원자료와 계약가격

공공 건설공사 단가는 민간 아파트 리모델링 계약가격과 직접 같다고 보지 않습니다. 원가 참고 데이터로 사용하고, 소비자 공종·수량·사양으로 다시 분류한 뒤 민간 견적 표본이 충분한 경우에만 통계로 공개합니다.

표본 기준

같은 공종이라도 철거 여부, 수량, 자재 규격, VAT 포함 여부가 다르면 직접 비교하지 않습니다. 비교 불가능한 항목은 가격판정 대신 확인 항목으로 표시합니다.

표시 용어

  • 모델 범위: 실제 표본 분포가 아닌 계산모델 결과
  • 중앙값/P25/P75: 조건을 정규화한 실제 표본이 충분한 경우에만 사용
  • 시장 평균: 출처와 표본이 명확하지 않으면 사용하지 않음
