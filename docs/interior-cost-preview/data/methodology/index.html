인테리어 견적 데이터 산출 원칙

공식 통계, 공공 참고단가, 사용자가 입력한 계산값, 실제 민간 견적은 서로 다른 데이터입니다. 같은 숫자처럼 섞지 않고 출처·기간·단위·포함조건을 함께 표시합니다.

데이터를 네 종류로 구분합니다

종류예시사용 범위
공식 통계건설공사비지수, 건설업 임금공표된 정의·기간·단위 그대로 표시
공공 참고자료표준시장단가공종 정의·규격·단위·포함조건 확인
계산값수량×단가, VAT, 지수 변화율사용자가 입력하거나 선택한 값만 산식으로 계산
민간 견적익명화·정규화한 실제 견적동일 조건을 맞춘 뒤 충분한 표본이 있을 때만 분포 표시

공공자료를 민간 평균 견적으로 바꾸지 않습니다

건설공사비지수는 시간에 따른 투입가격 변화를 보는 지표이고, 건설업 임금은 조사 대상 직종의 평균임금이며, 표준시장단가는 공공 건설공사 예정가격 산정 참고자료입니다. 이 숫자를 24평·32평 아파트 총액이나 특정 공종의 민간 시장 평균으로 직접 환산하지 않습니다.

미기재 값은 임의로 채우지 않습니다

견적서에 VAT, 폐기물, 샷시, 수량 또는 제품 사양이 적혀 있지 않다면 0원·무료·제외로 가정하지 않습니다. ‘포함’, ‘별도’, ‘미기재’를 구분하고 필요한 경우 업체에 확인한 뒤 비교합니다.

민간 견적 통계는 조건을 먼저 정규화합니다

정규화 항목예시
면적공급평수와 전용평수를 혼용하지 않음
공사 범위올수리·부분수리 구분
욕실공사 개수와 철거·방수·타일·도기 범위
샷시전체·부분·제외와 창 수량·사양
VAT·폐기물포함·별도·미기재 구분
지역다른 지역의 값을 빈 지역에 대입하지 않음

표본이 적으면 가격 분포를 숨깁니다

소수 사례의 평균이나 중앙값은 시장 전체를 대표하는 것처럼 오해될 수 있습니다. 견적검수실은 전체 분포와 지역·평수·공사범위 같은 세부 분포에 별도의 최소 표본 기준을 두고, 기준을 충족하지 못하면 가격 통계를 공개하지 않습니다.
