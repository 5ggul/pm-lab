데이터 산출 방법

공공 기준자료를 민간 인테리어 시장 평균으로 직접 사용하지 않습니다.

데이터 4단계

공공자료정부·공공기관 원자료
산식 추정원자료를 소비자 공종·수량·사양으로 환산
실제 견적 표본개인정보를 제거한 견적을 표준 항목으로 정리
표본 통계조건 일치 표본이 충분할 때 중앙값·P25·P75 공개

공공 기준자료의 역할

건설공사 표준시장단가와 표준품셈은 공공 건설공사의 예정가격 산정에 쓰이는 기준입니다. 일반 아파트 턴키 계약가격과 목적이 다르므로, 공종·노무·원가 변화의 참고자료로만 사용합니다.

견적 정규화

‘화장실공사’, ‘욕실 1식’, ‘욕실 리모델링’ 같은 표현을 욕실 공종으로 묶은 뒤 철거, 방수, 타일, 도기, 수전, 천장, 환풍기, 배관으로 세분합니다. 세부 사양이 없으면 금액 비교 결과 대신 ‘사양 확인’으로 표시합니다.

통계 공개 조건

표본 수, 기간, 지역, 평수 범위, VAT 환산 기준, 이상치 제외 기준을 함께 공개할 수 있을 때만 ‘표본 중앙값’이나 P25/P75라는 용어를 사용합니다.
