검색·오류 페이지에서도 유지되는 데이터 기준

이 페이지 자체의 정보가 짧더라도 사용자가 다음 행동을 결정할 수 있도록 사이트의 데이터 사용 기준과 연결 경로를 함께 제공합니다. 견적검수실에서 OFFICIAL은 기관이 공개한 공식 통계, REFERENCE는 공공 건설 예정가격을 위한 참고 단가, CALCULATED는 사용자가 직접 입력한 조건과 금액으로 만든 계산 결과, QUOTE는 개인정보를 제거한 민간 견적을 정해진 표본 기준으로 집계한 값입니다. 이 네 종류의 숫자는 서로 대체하지 않습니다. 특히 공공 표준시장단가는 민간 아파트 인테리어의 시장평균·적정가격·업체 추천 점수로 바꾸지 않으며, 공종명·규격·단위·재료 포함 여부가 같은지 확인하는 참고축으로만 사용합니다.

실제 민간 견적 가격분포는 전체 표본 N 30 이상, 지역·평수·공사범위 같은 세부 셀은 N 20 이상이라는 사이트 공개 기준을 충족해야 중앙값과 P25·P75를 노출합니다. 기준 미달이면 건수와 보류 상태만 표시합니다. 평균값은 소수의 큰 견적에 결과가 끌릴 수 있어 공개하지 않습니다. 견적 CSV 스키마는 이름, 전화번호, 이메일, 상세주소, 업체명, 사업자번호, 계좌, 서명 같은 식별정보 열을 허용하지 않으며 원본 행도 공개 저장하지 않습니다.

검색 결과가 없으면 평수별 페이지, 공사별 페이지, 공공단가 공종군, A/B/C 견적 비교 중 목적에 맞는 경로로 이동할 수 있습니다. 잘못된 주소로 들어온 경우에도 같은 연결을 사용합니다. 현재 사이트는 운영 배포 전 프리뷰이므로 모든 페이지를 noindex로 유지하고 있으며, 운영 전환은 사용자의 최종 검수 후 robots·canonical·사이트맵·광고 위치를 별도로 확인한 뒤 진행합니다.
