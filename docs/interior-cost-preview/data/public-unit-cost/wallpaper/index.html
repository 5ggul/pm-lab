자주 묻는 질문

5,993~8,531원을 도배 시장 시세로 보면 되나요?

아닙니다. 서로 다른 공공 공종과 바탕면 조건의 기준값입니다. 민간 견적은 제품, 실제 면적, 바탕 보수, 철거·폐기와 현장 조건을 별도로 확인해야 합니다.

내 견적의 ㎡ 단가와 바로 비교해도 되나요?

공종 정의와 포함 재료가 같은지 먼저 확인해야 합니다. 주재료 벽지가 포함된 소비자 견적을 주재료가 제외된 공공 항목과 바로 비교하면 의미가 달라집니다.
