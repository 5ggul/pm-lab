자주 묻는 질문

가장 낮은 ㎡ 단가가 가장 저렴한 타일 공사인가요?

아닙니다. 서로 다른 공법·규격·포함조건의 공공 항목이므로 단가 순위만으로 비교하지 않습니다.

욕실 전체 타일 견적에 이 단가를 곱하면 되나요?

민간 욕실 공사에는 타일 제품, 철거, 방수, 바탕면, 코너와 마감, 폐기물 등 다른 항목이 함께 들어갈 수 있어 직접 총액으로 대체할 수 없습니다.
