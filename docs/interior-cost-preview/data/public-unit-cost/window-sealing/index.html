적용범위 확인

창호·실링 단가를 민간 인테리어 시세로 봐도 되나요?

아닙니다. 이 페이지는 공공 건설 예정가격 참고용 표준시장단가를 공종별로 분류한 자료입니다. 주재료비 제외 여부와 규격이 서로 달라 민간 소비자 견적의 적정가격 판정에 사용할 수 없습니다.

창호·실링 단가 항목은 무엇을 먼저 비교해야 하나요?

같은 단위인지 확인한 뒤 공법·부위·규격·포함재료를 맞춰야 합니다. 단위가 같아도 규격이 다르면 단순 가격순위로 해석하지 않습니다.

실제 인테리어 견적과 어떻게 같이 보나요?

공공 단가는 작업 범위를 확인하는 참고축으로 쓰고, 실제 민간 견적은 견적 비교 도구에서 VAT·폐기물·창호 등 포함조건을 먼저 맞춥니다. 현재 민간 가격 통계는 표본 기준을 충족할 때만 공개합니다.
