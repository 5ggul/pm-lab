QUOTE DATA OPERATIONS

견적 데이터 운영 절차

수집 원본과 공개 통계를 분리하고, 개인정보 열은 입력 단계에서 차단합니다.

로컬 수집

사용자가 브라우저에서 익명 행을 만들고 CSV를 직접 내보냅니다. 서버 업로드는 없습니다.

비공개 검증

운영자는 PRIVATE.csv를 로컬/비공개 환경에서 스키마 검증합니다. 허용되지 않는 열이 있으면 집계를 막습니다.

집계 생성

원본 행을 docs에 쓰지 않고 N·P25·중앙값·P75와 커버리지 정보만 생성합니다.

N 게이트

전체 N≥30, 세부 셀 N≥20일 때만 가격 통계를 공개합니다.

검색 반영

지역×평수 셀이 기준을 통과해야 조합 가격 페이지가 생성·색인 후보가 됩니다.

운영 명령

원본 CSV 경로를 공개 저장소 밖에 둔 상태에서 실행합니다.

1) 공개 전 데이터 구조만 검사

node interior-cost-core/audit-quote-dataset-v11.mjs --input PRIVATE.csv --output /tmp/quote-audit.json

2) 집계 생성 시 비공개 입력 경로를 환경변수로 전달

INTERIOR_QUOTE_DATASET=/private/PRIVATE.csv node interior-cost-core/postprocess-review-date.mjs

원본 행·이름·전화번호·이메일·상세주소·업체명·계좌·서명은 공개 산출물에 포함하지 않습니다. 운영자가 수집한 원본 파일을 Git에 커밋하지 않는 것이 전제입니다.

입력 스키마quote-sample-schema.json
집계 계약quote-aggregate-contract.json
운영 계약quote-ops-contract-v11.json
현재 커버리지coverage dashboard
