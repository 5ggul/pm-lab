이 페이지는 검수 단계의 문서입니다. 실제 민간 견적 원본은 공개하지 않고 전체 N 30 이상, 세부 지역·평수·공종 셀 N 20 이상에서만 P25·중앙값·P75를 공개합니다. 공공 표준시장단가와 건설공사비지수는 민간 인테리어 시장평균이나 적정가격으로 환산하지 않습니다. 운영 robots·sitemap·광고 활성화는 소유자 승인 전까지 수행하지 않습니다.
