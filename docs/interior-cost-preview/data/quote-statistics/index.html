실제 인테리어 견적 통계 공개 기준

소수 견적을 시장 평균처럼 보이지 않게 하기 위해 조건을 맞춘 실제 견적이 충분히 쌓인 경우에만 가격 분포를 공개합니다. 현재 공개 기준을 충족한 가격 분포는 표시하지 않습니다.

어떤 통계를 공개하나요?

표시 항목의미
표본 수같은 조건으로 비교 가능한 실제 견적의 개수
P25정렬된 견적의 하위 25% 지점
중앙값정렬된 견적의 가운데 지점
P75정렬된 견적의 하위 75% 지점
기준 조건기간·지역·평수·공사범위와 VAT·폐기물·샷시 등 포함 조건

평균 하나만 제시하기보다 분포와 표본 수를 함께 보여 특정 고가·저가 견적이 전체 값을 과도하게 움직이는 문제를 줄입니다.

표본 수 기준

구분공개 기준기준 미달 시
전체 가격 분포비교 가능한 표본 30건 이상가격 분포 비공개
지역·평수·공사범위 등 세부 분포해당 조건 표본 20건 이상해당 세부 가격 비공개

표본 기준을 넘었다는 사실만으로 서로 다른 조건의 견적을 섞지 않습니다. 같은 가격축에서 비교할 수 있도록 조건 정규화를 먼저 적용합니다.

견적을 같은 조건으로 맞추는 항목

항목구분 방법
면적공급평수와 전용평수를 구분하고 같은 면적 기준끼리 비교
공사 범위올수리·부분수리와 실제 공종 범위를 구분
욕실·주방공사 개수, 가구 길이, 철거·방수·설비 이동 등 범위를 확인
샷시전체·부분·제외와 창 수량·사양을 구분
VAT·폐기물포함·별도·미기재를 구분해 총액 조건을 맞춤
지역·시점다른 지역이나 다른 시기의 값을 빈 조건에 임의 대입하지 않음

통계에서 제외하는 경우

중복 견적, 테스트 데이터, 필수 조건을 확인할 수 없는 견적, 총액의 포함 범위가 불명확해 같은 조건으로 환산할 수 없는 견적은 가격 분포에 넣지 않습니다. 미기재 값을 0원으로 채우거나 공공 표준시장단가를 실제 민간 견적처럼 섞지 않습니다.

개인정보와 업체 정보

통계는 개별 견적서를 그대로 공개하는 방식이 아니라 조건을 정규화한 집계값을 대상으로 합니다. 상세 주소, 연락처, 개인 식별정보처럼 통계에 필요하지 않은 정보는 공개 통계의 기준값으로 사용하지 않습니다.

자주 묻는 질문

표본이 적어도 참고용 평균을 보여주면 안 되나요?

소수 사례는 특정 업체·현장·사양의 영향을 크게 받아 시장 전체의 값처럼 오해되기 쉽습니다. 그래서 최소 표본 기준을 충족하기 전에는 가격 분포를 표시하지 않습니다.

공공 표준시장단가를 실제 견적 표본에 포함하나요?

아닙니다. 공공 참고단가는 공종 정의·규격·단위를 확인하는 자료이고 실제 민간 인테리어 견적과 별도 데이터로 관리합니다.
