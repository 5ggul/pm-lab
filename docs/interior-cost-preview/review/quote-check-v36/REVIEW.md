# 견적검수실 — 견적 확인 v36 검수본

2026-09-13. 기존 quote-check 화면을 대체하지 않는 별도 검수본.

## 구현
- 12개 핵심 공종을 한 화면에서 확인.
- 기재 / 별도 / 미기재 상태 구분.
- 미기재는 0원으로 계산하지 않음.
- 별도 항목의 금액 미확인, 비교에 필요한 사양·수량·단위 부족을 별도로 표시.
- 기재·별도 항목 중 유효하게 입력된 금액만 ‘확인된 입력합계’에 포함.
- 전체 / 미기재 / 별도 / 추가 확인 필터.
- 입력 상태에 맞춰 업체 질문 자동 생성.
- 브라우저 저장, 결과 복사, 확인 후 초기화.
- 데스크톱은 공종·상태·입력 필드가 한 줄 구조, 모바일은 공종별 세로 구조.

## 기존 화면과의 차이
기존 12단계 wizard 중심 구조를 없애고, 사용자가 전체 누락 상태를 즉시 확인할 수 있는 ledger형 인터페이스로 변경했다. 총액이나 시장평균을 앞세우지 않고 견적서 기재 상태와 비교 가능성을 먼저 본다.

## 데이터 원칙
이 검수본은 실제 견적 통계나 시세를 새로 만들지 않는다. 사용자가 직접 입력한 값만 계산한다. 공공 단가·민간 표본 데이터는 별도 데이터 레이어에서만 연결한다.
