계산 기준

확인된 입력합계 = ‘본견적 기재’ 금액 + ‘별도 금액’. 확인하지 않은 추가비가 있으면 최종 지급액과 다를 수 있습니다.

미입력과 0원은 다릅니다. 빈칸은 금액 미확인입니다. 0은 실제로 금액이 없다고 확인한 경우에만 입력합니다. 음수·문자·지수 표기는 합산하지 않습니다.

중복 금액은 제외합니다. 욕실 금액에 방수가 포함되거나 공종별 금액에 VAT가 이미 포함됐다면 해당 행은 ‘다른 항목에 포함’을 선택합니다. VAT를 자동 추정하거나 덧붙이지 않습니다.

업체 간 차이는 모든 공종의 조건과 필요한 금액이 확인되고, 포함조건이 같으며, 범위·수량·사양 확인을 체크한 경우에만 표시합니다. 저렴한 업체나 적정 시공비를 판정하지 않습니다.
