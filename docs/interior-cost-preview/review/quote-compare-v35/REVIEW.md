## 구현

A/B 기본 비교와 C 추가·제외. C를 제외해도 입력값을 지우지 않는다. 모바일은 업체별 입력을 전환하고 요약에서는 모두 표시한다.

12공종에서 미확인 / 본견적 기재 / 별도 금액 / 다른 항목에 포함 / 공사·금액 없음 상태를 구분한다. 빈칸을 0원으로 간주하지 않는다. 원 단위 정수로 계산하며 음수·지수 표기·잘못된 쉼표·초과 정밀도는 합산하지 않는다.

미확인 금액과 중복 포함 금액을 제외하고 본견적·별도를 구분한다. 조건·금액 확인과 동일 공사범위·수량·사양 체크가 끝나야 업체 간 차이를 표시한다. 금액·상태·업체 수 변경 또는 저장값 복원 시 범위 확인을 해제한다. 그래프는 같은 눈금의 입력값 누적 막대다. 시장평균·적정가격·업체 순위를 만들지 않는다.

필터, 확인 질문, 복사 실패 시 직접 복사 대화상자, CSV, 인쇄용 전체 표, 확인 후 초기화를 구현했다. 저장 키는 interior-compare-v35. 이전 v5 키는 건드리지 않는다. 손상·읽기 실패·다른 탭 변경 시 조용히 덮어쓰지 않는다.
