# Interior v51 unified review status

비운영 검수 전용 단계입니다.

## 목적

v43~v50에서 누적된 검수 기능의 현재 진행 상태를 리포트 상단 한 곳에서 요약합니다.

상태판은 아래 6단계를 읽습니다.

1. 견적 저장
2. A/B/C 업체 비교
3. 업체 답변 확인
4. 서면 반영 확인
5. 검수 기준 스냅샷
6. 변경 후 재검수

첫 미완료 단계 하나만 `다음 확인`으로 안내합니다.

## 다음 행동 우선순위

- 견적 미저장 → 견적 입력
- 견적 저장 / 비교 미저장 → A/B/C 비교
- 업체 질문 미완료 → 업체 답변 확인
- 완료 답변 중 서면 반영 미확인 → 서면 반영 확인
- 검수 기준 미저장 → 현재 상태를 기준으로 저장
- 기준 이후 변경 + 재검수 미완료 → 재검수 진행
- 기준 이후 변경 + 재검수 완료 → 새 검수 기준 저장
- 기준과 현재 값 동일 → 추가 재검수 없음

## 저장 정책

v51은 새 localStorage 키를 만들지 않습니다. 기존 v43~v50 데이터를 읽기만 하며 어떠한 저장값도 자동 수정하지 않습니다.
