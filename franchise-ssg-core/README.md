# 창업데이터랩 SSG 생성기

`docs/franchise-data-preview/data-final.js`의 170개 카탈로그와 `data/franchise/official/brands-2025.json`의 공정거래위원회 공개자료 스냅샷을 읽어 `docs/franchise-ssg-preview/`에 정적 HTML을 생성합니다.

## 현재 원칙

- GitHub Pages 프리뷰는 모든 HTML을 `noindex,nofollow,noarchive,nosnippet`으로 유지합니다.
- 실제 운영 색인 후보와 프리뷰 색인 상태를 분리합니다. 운영 배포 전에는 프리뷰에서 index를 열지 않습니다.
- 합성값을 공식값처럼 보여주지 않습니다. 공식 매칭이 확인되지 않은 값은 0으로 채우지 않습니다.
- 브랜드명 fuzzy 자동매칭은 사용하지 않습니다. 정확 일치, 검수 alias, 검수 제외만 허용합니다.
- 점포 이력의 전 항목 0 placeholder는 실제 0으로 단정하지 않고 추이에서 제외합니다.
- 추천·유망·성공·수익성 점수는 만들지 않습니다. 평균매출 공개값도 순이익으로 표현하지 않습니다.
- 대량 파생 랜딩페이지를 만들지 않고, 검색 의도별 통합 허브를 소수 운영합니다.

## 현재 데이터 신뢰 게이트

- 카탈로그: 170개
- 공식 레코드 매칭: 149개
- 검수 제외: 21개
- Tier A: 정제된 점포 이력 3개년 이상 + 출처·기준연도·비용·가맹점·평균매출·비용 4항목·신규/종료/해지 완전
- Tier B: 연속 2개년 점포 이력 + Tier A의 나머지 필드/콘텐츠 게이트 완전
- Tier C: 이력 부족 또는 연속성 불충분. 상세 HTML은 존재해도 정식 색인 후보에서 제외

현재 Tier A/B 신뢰 브랜드는 136개입니다.

## 주요 검색·의사결정 허브

- `/brands/` — 브랜드 검색·정렬
- `/categories/` — 업종별 분포·중앙값·범위
- `/explore/` — 5천만원·7천만원·1억원·1억5천만원·2억원 공개비용 예산 탐색
- `/rankings/` — 공개 창업비용·가맹점·평균매출 공개지표 통합 정렬
- `/compare/` — Tier A/B 136개 중 두 브랜드를 같은 화면에서 직접 비교. 검증된 일부 조합만 정적 상세 URL 유지
- `/cost-components/` — 가맹비·교육비·본사 보증금·기타비용 비교. 공개값 0을 면제/무료로 재해석하지 않음
- `/tools/` — 신뢰 게이트를 통과한 실사용 계산·분석 도구 허브

검색 의도 허브는 각각 한 URL에 통합하며 `1억원 이하`나 `가맹비 0` 같은 조합별 정적 페이지를 대량 생성하지 않습니다.

## 공식 데이터 매칭

`official-merge.mjs`가 카탈로그와 공식 Snapshot을 분리해서 매칭합니다.

- 브랜드명 정규화 정확 일치를 우선합니다.
- 정확 일치가 없을 때만 검수된 alias의 고유 일치를 허용합니다.
- 같은 공식 브랜드명이 여러 레코드에 존재하면 자동 선택하지 않고 `AMBIGUOUS`로 둡니다.
- 중복 canonical, 단일 매칭 불확실, umbrella 브랜드는 검수 제외 사유를 명시합니다.
- 창업비용·가맹점·평균매출·가맹비·교육비·보증금·기타비용은 공식 필드만 사용합니다.

## 콘텐츠·색인 품질

- 브랜드 상세: 비용 구성, 점포 이력, 업종 중앙값 비교, 업종 내 위치, FAQ, 출처를 실제 데이터로 구성합니다.
- 업종 상세: 분포, 산점도, 중앙값, 최저·최고 비용, 가맹점·평균매출 범위를 포함합니다.
- `Dataset` JSON-LD는 실제 페이지에 노출된 공식/파생 수치만 담습니다.
- 브랜드·업종·비교·도구 색인 후보는 Thin content 자동검사를 통과해야 합니다.
- 내부 권위 postpass가 production 후보의 도달 가능성, 허브 커버리지, orphan, crawl depth를 매번 감사합니다.
- 프리뷰에서는 robots.txt와 sitemap도 검색엔진 유입을 막는 상태를 유지합니다.

## 정식 공개 게이트

- 공식 데이터와 콘텐츠 신뢰 게이트 통과
- 운영주체·연락처·정책 페이지 실제 정보 확정
- production candidate 전체 내부링크·canonical·robots·sitemap 검증
- 사용자 검수 승인

이 조건이 끝나기 전에는 실제 운영 도메인의 색인을 열지 않습니다.

## 실행

```bash
npm --prefix franchise-ssg-core run build
```

`package.json`의 v11 파이프라인이 순서대로 생성·검증되며, 프리뷰 생성 후 별도 internal-authority postpass가 내부 링크 구조를 다시 감사합니다.
