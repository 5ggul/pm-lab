# 창업데이터랩 SSG 생성기

`docs/franchise-data-preview/data-final.js`의 전체 카탈로그와 `data/franchise/official/brands-2025.json`의 공식 스냅샷을 읽어 정적 HTML을 `docs/franchise-ssg-preview/`에 생성합니다.

## 현재 프리뷰 규칙

- 모든 HTML은 `noindex,nofollow`입니다.
- 해시 라우팅을 사용하지 않습니다.
- 현재 카탈로그 170개 브랜드의 기본 상세 `/brands/{slug}/`를 전부 생성합니다.
- 기존 검수 42개 브랜드는 고정 영문 slug를 유지하고, 나머지는 번호형 ID 대신 브랜드 상호를 정규화한 영구 slug를 사용합니다.
- `/categories/`에서 20개 업종, `/areas/`에서 12개 지역, `/themes/`에서 숫자 조건별 브랜드를 탐색합니다.
- `/areas/compare/`에서 두 지역의 전체 업소·외식 업소·면적·업종별 공급 밀도를 비교합니다.
- `/compare/` 허브와 선별 비교 10개를 생성합니다.
- 도구는 9개이며 조건 브랜드 필터, 총 창업비용 계산기, 월 손익 시뮬레이터 등을 제공합니다.
- 창업비용 계산기의 브랜드 선택 목록도 전체 170개 카탈로그와 동기화합니다.
- `/cost/`와 `/stores/` 프리뷰 템플릿은 10개 핵심 브랜드만 유지합니다.
- 정식 `/cost/`는 공식 출처·기준연도·3개년 이상 비용 이력·4개 이상 비용 구성이 있어야 독립 페이지 후보가 됩니다.
- 정식 `/stores/`는 공식 출처·기준연도·3개년 이상 점포 이력·신규/종료/해지 정보가 있어야 독립 페이지 후보가 됩니다.

## v7 사용자 화면

- 홈 첫 화면은 `브랜드 검색 → 조건 필터 → 브랜드 비교 → 창업비용 계산 → 월 손익 계산`을 바로 노출합니다.
- 홈 카피는 사이트 철학 대신 실제 제공 기능과 데이터 종류만 설명합니다.
- 상단 메뉴는 `브랜드 찾기 / 업종 / 브랜드 비교 / 지역 / 계산기 / 가이드`로 단순화했습니다.
- 브랜드 목록은 데스크톱에서 브랜드명·업종·공개비용·가맹점·전년 증감을 한 줄에 읽는 데이터 리스트형이며 모바일에서는 카드형으로 전환합니다.
- 홈에는 170개 브랜드, 20개 업종, 12개 지역, 9개 도구 규모를 바로 표시합니다.
- 추천·유망·성공 점수는 만들지 않습니다. 지역 밀도도 공급 관찰값으로만 표시합니다.
- 현재 프리뷰 숫자는 합성값이므로 공식 데이터 연결 전까지 noindex를 유지합니다.

## 공식 데이터 매칭

`official-merge.mjs`는 SSG 카탈로그와 공정위 공식 Snapshot을 별도로 매칭합니다.

- 브랜드명 정규화 정확 일치를 최우선으로 사용합니다.
- 정확 일치가 없을 때만 카탈로그에 이미 정의된 alias의 고유 일치를 허용합니다.
- fuzzy/유사도 자동매칭은 사용하지 않습니다.
- 같은 공식 브랜드명이 여러 레코드에 존재하면 자동 선택하지 않고 `AMBIGUOUS`로 분류합니다.
- 매칭 결과는 `docs/franchise-ssg-preview/official-match-report.json`에 기록합니다.
- 공식 Snapshot이 준비돼도 카탈로그 미매칭 또는 중복 매칭이 남으면 합성값과 공식값을 섞지 않습니다.
- 전체 카탈로그가 안전하게 매칭되고 핵심 비교 브랜드의 비용·점포 값이 준비된 경우에만 공식 프리뷰 병합이 활성화됩니다.
- 병합 시 창업비용·가맹점·전년 점포·매출·가맹비·교육비·보증금·기타비용을 공식 필드로 교체하고, 존재하지 않는 공식 필드는 `정보 없음`으로 둡니다.

지역 상권 데이터는 별도 소상공인 상권 API Snapshot을 연결할 예정이며, 현재 지역 숫자는 구조 검수용 합성값입니다.

## 정식 공개 게이트

- `officialMetricMergeReady`: 공식 Snapshot을 SSG에 병합할 코드가 준비됐는지
- `officialSnapshotReady`: 실제 공공데이터 Snapshot이 품질 게이트를 통과했는지
- `operatorIdentityReady`: 운영주체 정보가 준비됐는지
- `realContactReady`: 실제 연락처가 준비됐는지

현재 인증키/공식 Snapshot이 준비되지 않았으므로 공식 병합은 비활성이고 프리뷰는 합성 구조값 + `noindex` 상태를 유지합니다. `noindex` 제거는 마지막 단계입니다.

## 실행

```bash
npm run build
```

기본 스크립트는 `run-generate-v7.mjs` → `run-validate-v7.mjs` 순서로 실행합니다.
