# 픽마이카 차량별 커뮤니티

## 확정 범위

- 차량별 질문, 실사용 후기, 댓글. 자유게시판과 사진 첨부는 첫 범위에서 제외한다.
- 읽기는 비로그인 공개, 쓰기는 Google 로그인 후 가능하다.
- 공식 신고 사양과 사용자 경험을 별도로 표시한다. 후기를 계산·순위의 공식 데이터에 섞지 않는다.
- 기존 `family_id`로 차량과 글을 연결한다. 새 차량이 수집되어도 게시판 코드를 추가하지 않는다.
- 자동차 원본·계산식·자동 갱신은 유지한다. 커뮤니티 데이터는 별도 Supabase 프로젝트에 보관한다.
- 현재 작업은 별도 브랜치 및 미리보기에서 검수한다.

## 화면

기존 지면·타이포·간격을 재사용한 행 중심 게시판. 장식 히어로와 가짜 인기 글을 만들지 않는다.

1. 커뮤니티: 차종 검색, 전체/질문/실사용 후기, 최신 글 목록, 글쓰기.
2. 글 상세: 차종·유형, 제목, 닉네임·작성일, 본문, 댓글, 신고.
3. 글쓰기: 차종, 유형, 제목, 본문. 후기는 엔진·구동·주행 조건을 본문에서 설명하도록 안내한다.
4. 내 글만 수정·삭제. 다른 회원의 이메일이나 Google 실명은 공개하지 않는다.
5. 차량 상세에는 해당 차종의 질문·후기로 연결되는 링크를 둔다.

## 데이터와 권한

- 게시글·댓글·신고·공개 닉네임을 분리한다.
- 공개 읽기와 소유자 편집을 데이터베이스 권한으로 제한한다. 화면에서 버튼을 감추는 것으로 대신하지 않는다.
- 신고 내역은 다른 회원에게 공개하지 않는다. 관리 권한은 사용자가 바꿀 수 있는 프로필 필드에 두지 않는다.
- 작성 제한, 길이 제한, 삭제된 글의 댓글 작성 금지, 중복 신고 방지는 서버에서 검사한다.
- 게시물 본문은 텍스트로 출력한다. 사용자 HTML은 실행하지 않는다.
- 빈 목록, 데이터 오류, 로그인 실패, 삭제된 글은 서로 다른 상태로 표시한다.
- 로컬 샘플은 실제 회원 글처럼 게시하지 않는다.

## 공개 전 조건

- 프로젝트 생성 및 Google OAuth 설정.
- 읽기, 로그인, 글·댓글 작성/수정/삭제, 신고, 관리자 숨김의 실제 저장·권한 검증.
- 375/390/768/1280px, 키보드, 로그인 복귀 경로, 새로고침 검증.
- 커뮤니티 운영정책과 개인정보 안내 반영. 미검수 사용자 글은 기본 noindex.
- 자동 생성 재실행 후 연결 유지 및 기존 계산·비교 회귀 확인.

## 외부 설정 대기

무료 프로젝트 한도 때문에 전용 프로젝트 생성이 거절됐다. 사용자의 선택에 따라 기존 `oreun-r1-preview` (`galfwxoytdcndjihdnyg`)를 검수에만 공유한다. 기존 `community_posts`와 충돌하지 않도록 신규 테이블은 `pmc_*`, 내부 함수는 `pmc_private`로 분리했다. 기존 테이블·Site URL·Google provider 자격 증명은 수정하지 않았다. 실제 Google provider는 이미 활성화되어 있다.

## 로컬 실행과 확인 범위

`npm ci`, `npm run build`, `npm run dev` 후 `http://127.0.0.1:4190/community/`에서 확인한다.
`npm test`는 PGlite의 실제 PostgreSQL에서 DDL과 두 사용자·비회원의 권한을 확인한다. Auth 헬퍼만 로컬로 대체한다.
`npm run test:preview`는 서버가 실행 중일 때 4개 폭에서 차종 필터와 미연결 상태를 확인한다. 필요하면 `PLAYWRIGHT_EXECUTABLE_PATH`에 로컬 브라우저 경로를 지정한다.

현재 확인 완료: SQL 권한/소유자 검사/삭제글 접근/신고 비공개/중복신고/작성 제한, 미연결 화면 375·390·768·1280px overflow 0·JS 오류 0.
추가 확인 완료: Supabase 전용 스키마 적용, 차종 440개 등록, 실제 REST의 비회원 읽기 및 쓰기·신고·프로필 접근 차단, Vercel 검수본 4개 폭의 가로 넘침/JS 오류 없음, 구글 인증 화면 진입.
아직 미확인: Google OAuth 로그인 왕복, 회원의 실제 서버 글·댓글 저장, 관리자 화면, 운영 페이지 연결. 현재 운영 배포에는 이 기능이 포함되지 않는다.

## 검수 배포와 로그인 복귀

- `node build-preview.mjs`는 기존 사이트 전체 + 커뮤니티를 별도 Vercel 검수 프로젝트로 묶는다.
- `review-config.json`은 공개용 키만 포함한다. service_role, Google Client Secret, 로그인 세션을 저장하지 않는다.
- 검수 주소: https://peekmycar-community-review.vercel.app/community/
- HTML 메타와 HTTP `X-Robots-Tag` 모두 noindex/nofollow/noarchive. noindex는 접근 제한이 아니다.
- Supabase Authentication → URL Configuration → Redirect URLs에 `https://peekmycar-community-review.vercel.app/community/**`를 추가해야 한다. 기존 Site URL과 주소는 유지한다.
- Google provider의 기존 OAuth 클라이언트를 검수에 재사용하므로 Google 동의 화면에 기존 서비스 명칭이 표시될 수 있다. 정식 커뮤니티 출시 전에 전용 앱·저장 공간 분리를 검토한다.
- 실제 로그인 및 글쓰기 검수가 끝나기 전에는 정식 도메인에 병합·배포하지 않는다.
